## Задача 1 — ЦВЕТ

```diff
- color: #e6b800;      → color: #E5AC3A;
- border: ...rgba(255,200,60,0.35) → rgba(229,172,58,0.35)
- background: rgba(255,200,60,0.06) → rgba(229,172,58,0.06)
- border-bottom: rgba(255,200,60,0.15) → rgba(229,172,58,0.15)
- color: #e6b800 (item-days) → color: #E5AC3A
```

**Палитра блока долга:**
- `#E5AC3A` — токен предупреждающего цвета (заголовок, дни до сгорания)
- `rgba(229,172,58,0.35)` — рамка блока
- `rgba(229,172,58,0.06)` — фон блока
- `rgba(229,172,58,0.15)` — разделитель заголовка
- `var(--text)` — текст задачи, даты
- `var(--muted)` — подсказка, уровень
- `rgba(255,255,255,0.03)` — фон элемента
Все цвета из палитры проекта.
