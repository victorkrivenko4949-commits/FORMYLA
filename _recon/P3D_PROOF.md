## ЗАДАЧА 1. ИСПРАВЛЕННАЯ get_daily_task_count()

**Правка применена** в [`services/daily_task_rotation.py`](services/daily_task_rotation.py:44).

**Номер дня цикла**: [`curator/monthly_cycle._get_monthly_cycle()`](curator/monthly_cycle.py:42) → поле `day_index`.

Было:
- Переключение по `onboarding_done` (False → 5, True → норма из анкеты).
- После прохождения анкеты (день 1) сразу норма 10, режим 5 задач никогда не наступал.

Стало:
- Дни 1..7 цикла → 5 задач (режим зондирования).
- День 8+ → норма из анкеты, по умолчанию 10.
- Если цикл не начат → день 1.

```python
def get_daily_task_count(user_id: int) -> int:
    from curator.monthly_cycle import _get_monthly_cycle
    cs = CuratorState.query.filter_by(user_id=user_id).first()
    if cs:
        mc = _get_monthly_cycle(cs)
        day_index = mc.get('day_index', 1)
    else:
        day_index = 1  # цикл ещё не начат — считаем день 1
    if day_index <= 7:
        return CUTOFF_DAILY_TASKS  # 5
    onboard = _get_onboarding(user_id)
    if onboard:
        n = onboard.get('daily_tasks')
        if isinstance(n, (int, float)) and n > 0:
            return int(n)
    return DEFAULT_DAILY_TASKS  # 10
```
