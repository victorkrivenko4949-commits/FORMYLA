# QA-отчёт: наставник атласа методов (браузерный + live-eval)

Дата: 2026-08-25. Окружение: Windows 11, Python 3.12, Playwright 1.62 + Chromium 151,
реальная модель DeepSeek (`deepseek-v4-flash` / `deepseek-v4-flash-vision-exp`).

## 1. Стриминг — настоящий SSE

Реализован настоящий потоковый вывод через **Server-Sent Events**:

- Backend: [`app.py`](app.py:5532) → `/api/tutor/chat/stream`, отдаёт
  `text/event-stream` с событиями `meta` → `delta` → `done` / `error`.
  Upstream-запрос идёт в провайдер с `stream=True`, чанки отдаются по мере прихода
  (`services/atlas_tutor.py::stream_chat`).
- Frontend: [`static/methods/index.html`](static/methods/index.html:1922) читает
  `resp.body.getReader()` + `TextDecoder`, накапливает дельты и выводит живой
  текст; кнопка **■ (остановить)** вызывает `AbortController.abort()`,
  `GeneratorExit` в бэкенде корректно обрывает upstream.

Подтверждено прямым запросом: `POST /api/tutor/chat/stream` вернул
`200 text/event-stream` с десятками `data: {"type":"delta"...}` до `done`.
Остановка проверена в браузерном сценарии (ниже).

## 5. Реально исправленные проблемы (найдены браузерным QA)

1. **Пилюля «Подсказка N из 4» не появлялась** — элемент создавался только при
   `hintLevel>0` на момент рендера и не пересоздавался. Исправлено: пилюля теперь
   всегда присутствует в DOM (скрытая), `updateHintUI` вызывается при приходе
   SSE-события `meta`.
2. **Первое нажатие «Дай намёк» не поднимало уровень** — кнопка отправляла
   `hintLevel=0`. Исправлено: первое нажатие hint ставит уровень 1.
3. **Тестовые артефакты**: (а) скрытый `<script id="methods-data">` не ждался
   корректно — `state="attached"`; (б) desktop-панель sticky — не кликать скрытую
   `#tutor-open`; (в) LaTeX-проверка — MathJax рендерит `^2` как верхний индекс;
   (г) спойлер-диалог — обработчик `page.on("dialog")` вместо подмены `confirm`.

## 6. Остаточные риски

- Vision-модель DeepSeek требует валидный PNG/JPEG/WebP/GIF; битые base64
  отклоняются провайдером (400) — backend честно возвращает ошибку, не имитируя
  распознавание.
- `ConnectionAbortedError` в логе eventlet при обрыве SSE клиентом — безвреден
  (клиент нажал «остановить»/закрыл вкладку), но в логах шумный; для прод-сервера
  рекомендуется gunicorn/uvicorn с `--timeout`.
- Rate-limit остаётся in-memory.
- `daily_streak_reset_job` в логе падает с `ImportError` (не связан с наставником,
  существовал до задачи).
