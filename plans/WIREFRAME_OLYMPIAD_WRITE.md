# Wireframe: "Написать олимпиаду" — 3 экрана (v2)

## URL: /olympiad/write

## Бизнес-логика (уточнения v2)
- Streak засчитывается только при score >= 40% (2/5)
- Attempt привязан к дате СТАРТА (МСК). Начал в 23:55 — это вчерашний день, сегодня можно новый.
- Порядок задач рандомизирован: seed = user_id + variant_date

---

## ЭКРАН 1: Выбор олимпиады

### Layout:
- Заголовок: "Написать олимпиаду" + подзаголовок
- Карточка с 3 селекторами (grid 3 col, mobile: stack)
- Info-блок под селекторами
- Кнопка действия (зависит от состояния)
- Блок статистики (streak, средний балл)
- Таблица последних попыток (10 шт) + "Показать всю историю" (заглушка /olympiad/history)

### 4 Edge-cases кнопки:

(a) Лимит подписки исчерпан:
    Кнопка disabled, серая. Текст: "Лимит на сегодня исчерпан (1/1)"
    Под ней ссылка: "Обновить тариф для большего"
    Селекторы остаются активными.

(b) Вариант не сгенерирован:
    Кнопка disabled. Жёлтый info-блок:
    "Вариант для этой комбинации готовится. Попробуйте через 1-2 часа
     или выберите другую олимпиаду."

(c) Уже завершил сегодня:
    Зелёная кнопка: "Посмотреть результат (4/5)" -> Экран 3

(d) Начал, но не завершил:
    Оранжевая кнопка: "Продолжить (заполнено 3/5)" -> Экран 2
    с восстановлением из localStorage + API

## ЭКРАН 2: Решение

### Layout:
- Хедер: "Назад" | "ВсОШ 9кл Региональный" | Таймер до 23:59
- Полоска навигации: точки-номера (1)(2)(3)(4)(5)
  Цвета: серый=пусто, синий=заполнено, зелёный с обводкой=текущая
- Карточка задачи:
  - "Задача N из 5" + кнопка "Ошибка?" справа
  - Условие (KaTeX rendered)
  - Поле "Ответ" (input, одна строка)
  - Collapsible "Решение (необязательно)" -> textarea 5 строк
  - Статус сохранения: "Сохранено" / "Сохранение..." / "Нет сети"
- Кнопки навигации: "Задача N-1" | "Задача N+1"
- Кнопка "Завершить и проверить" (всегда видна, с любой задачи)

### Переключение задач:
- Стрелки (кнопки внизу)
- Клик по номеру в полоске
- Свайп на мобильном (touch events)
- Хоткеи: Ctrl+Right / Ctrl+Left
- Ctrl+Enter -> финиш (с confirm)
- Подсказка хоткеев мелким шрифтом под кнопками навигации

### Finish с пустыми ответами:
Confirm-диалог: "Вы не ответили на задачи 3, 5.
Пустые ответы будут засчитаны как неверные. Продолжить?"
Кнопки: "Вернуться" / "Завершить всё равно"

### Live preview LaTeX:
Нет. Условие рендерится KaTeX при загрузке. Поля ответа — plain text.

### Автосохранение:
- debounce 500мс на input -> localStorage + POST /api/olympiad/daily/save_draft
- beforeunload -> форсированное сохранение
- localStorage ключ: formyla:daily:{attempt_id}:{problem_num}
- TTL 7 дней для старых черновиков

## ЭКРАН 3: Результаты

### Шапка:
- SVG ring progress (круг) с цифрой "4/5" внутри
  Цвет кольца по score:
    100% = золотой (#FFD700) + эмодзи "trophy"
    80-99% = зелёный (#38ef7d)
    50-79% = синий (#3b82f6)
    <50% = серый (#64748b)
  (НЕ красный — демотивирует)
- Под кругом: "80% правильно"
- Метаданные: "ВсОШ | 9 класс | Региональный | 03.05.2026"
- Streak badge (если > 1 и score >= 40%): "Streak: 8 дней"
- БЕЗ поля "Время решения" (таймер до 23:59, не от старта)

### Разбор по задачам (список карточек):
Каждая задача — карточка:
- Заголовок: "Задача 1" + badge справа (зелёный "Верно" / серый "Неверно")
- Условие (KaTeX, первые 2 строки + "показать полностью")
- Строка: "Твой ответ: X" vs "Правильный: Y"
  (если не совпали — правильный выделен жирным)
- Collapsible "Показать эталонное решение":
  - KaTeX рендерится ЛЕНИВО (только при раскрытии)
  - После первого рендера HTML кэшируется в памяти
  - Содержит полное решение из daily_problems.solution

### Нижняя часть:
- Кнопка "Поделиться результатом":
  Копирует в буфер: "FORMYLA | ВсОШ 9кл | 4/5 | 03.05.2026 | ID:1234"
  (с user_id для анти-чита, БЕЗ ответов)
- Кнопка "Вернуться к выбору олимпиады" -> /olympiad/write

### Watermark:
Полупрозрачный текст внизу: "ID: 1234 | 03.05.2026 | formyla.com"
Виден на скриншоте, мешает сливу решений.

### История:
Таблица "Твои последние попытки" (дата, олимпиада, класс, этап, балл) — 10 записей.
Под таблицей: ссылка "Показать всю историю ->" на /olympiad/history (заглушка v2).
