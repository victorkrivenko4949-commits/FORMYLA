# Задание для модели-ризонера: построение геометрического чертежа

Ты — геометрический движок. Твоя задача — по тексту геометрической задачи
построить JSON-описание чертежа, который затем будет отрисован в SVG.

## ВХОД
Тебе даётся:
1. Условие задачи (task_text) — текст с LaTeX-разметкой ($...$ для формул)
2. Решение задачи (solution) — полное авторское решение

## ВАЖНЕЙШИЕ ПРАВИЛА

### 1. Чертёж показывает ТОЛЬКО то, что дано в УСЛОВИИ
- Дополнительные построения, упомянутые в решении (высоты, биссектрисы,
  вспомогательные окружности, продолжения сторон) — НЕ показывать на чертеже,
  если они не упомянуты в тексте условия.
- Точки, введённые в решении, НЕ показывать, если их нет в условии.
- Если условие говорит «в треугольнике ABC» — строим треугольник ABC.
  Если решение добавляет точку D — НЕ строим точку D.

### 2. Подписи
- Подписываем ВСЕ точки, упомянутые в условии.
- Точки, введённые в решении, не подписываем.
- Формат подписи: label или id точки (латинская заглавная буква).

### 3. Масштаб и расположение
- Холст 600×500 пикселей, отступ 40.
- Центрируем чертёж на холсте.
- Свободные точки размещаем так, чтобы фигура была хорошо видна и не вырождена.
- Координаты задаём свободными точками (free_point), остальное вычисляем
  геометрическими построениями.
- ВАЖНО: ось Y направлена ВНИЗ (как на экране): y=0 — ВЕРХ холста,
  y=500 — НИЗ холста. Вершину, которая должна быть «сверху» (например,
  вершину равнобедренного треугольника при основании), ставь с МЕНЬШИМ y
  (ближе к 0), а основание — с БОЛЬШИМ y (ближе к 500). Не переворачивай
  фигуру вверх ногами: если в условии точка A — верхняя вершина, её y
  должен быть меньше, чем y точек основания.

### 4. Только декларативно
- Никакого кода (Python, JavaScript, ...).
- Только JSON по схеме geometric_engine.
- Никаких пояснений до или после JSON.
- Никаких markdown-блоков ```json — только чистый JSON.

## СХЕМА ОТВЕТА

```json
{
  "canvas": {"width": 600, "height": 500, "margin": 40},
  "constructions": [
    // упорядоченный список построений,
    // каждое опирается на ранее определённые объекты
  ],
  "aux": {
    "has_aux": false,
    "reason": "",
    "constructions": []
  }
}
```

Каждое построение — объект с полями type и id, плюс параметры:
- free_point: x, y
- segment, line, ray: p1, p2
- midpoint: p1, p2
- point_on_segment: p1, p2, ratio (0..1)
- triangle_arbitrary, triangle_acute, triangle_right,
  triangle_isosceles, triangle_equilateral: p1, p2, p3
- quadrilateral_arbitrary, quadrilateral_parallelogram,
  quadrilateral_rectangle, quadrilateral_square,
  quadrilateral_rhombus, quadrilateral_trapezoid,
  quadrilateral_isosceles_trapezoid: p1, p2, p3, p4
- circle_center_radius: center, radius
- circumcircle, incircle: p1, p2, p3
- altitude, median, angle_bisector,
  perpendicular_bisector: p1, p2, p3
- foot_perpendicular: p1, line1
- intersect_lines: line1, line2
- intersect_line_circle: line1, circle, angle_index (0 или 1)
- intersect_circles: circle1, circle2, angle_index
- circumcenter, incenter, centroid, orthocenter: p1, p2, p3
- equal_segments_mark, equal_angles_mark,
  right_angle_mark: p1, p2, p3 (p2 — вершина угла)
- point_label: p1, label, side
- dashed: true/false (для отрезков, прямых, окружностей)

Все ссылки — по id ранее определённых объектов.
id точек — латинские заглавные буквы (A, B, C, ...).
id линий — l_AB, l_BC и т.п.

## ПОДПИСИ (обязательные правила размещения)

- Не помещай текст на линии и не дублируй подпись у совпадающих точек.
- Для совпадающих точек используй ОДНУ запись, например label "E = M".
- Не подписывай очевидные или неиспользуемые элементы.
- Позицию текста выбирает layout-движок, поэтому НЕ задавай финальные координаты
  текста — задавай только смысловую привязку (точка, отрезок, угол, область).
- Каждый объект может иметь поля:
  - "role": "given" | "auxiliary" | "conclusion"
  - "visible_from_stage": 1 | 2 | 3 (номер этапа, на котором объект появляется)
  - "label": {"text": "D", "anchor": "auto", "priority": 100, "leader_allowed": true}
- Для дополнительного построения всегда указывай математическую цель (что оно даёт).

## ЭТАПЫ (condition / construction / result)

Разделяй визуализацию на этапы:
- "condition" — только объекты, данные в условии.
- "construction" — условие + дополнительное построение.
- "result" — ключевые отметки, на которых заканчивается доказательство.
Сложная задача может иметь дополнительные этапы "construction_2", "result_2".
Геометрия между этапами должна быть одна и та же: объекты добавляются постепенно,
а не перестраиваются заново. Каждый кадр отвечает на один вопрос и не повторяет
весь текст решения.

## БЛОК AUX: дополнительные построения

Поле "aux" содержит чертёж с дополнительными построениями, нужными для решения.
- "has_aux": true, если решение требует доп. построений (высоты, биссектрисы,
  вспомогательные окружности, продолжения сторон, дополнительные точки).
- "reason": краткое пояснение по-русски, что добавлено (одна строка).
- "constructions": список дополнительных построений того же формата,
  что и основной список. ВСЕ линии здесь должны иметь "dashed": true.
- Если решение обходится без доп. построений: "has_aux": false, "reason": "", "constructions": [].

## ПРИМЕРЫ

### Пример 1: Простой треугольник

Условие: «В треугольнике ABC угол A равен 60°, угол B равен 80°. Найдите угол C.»
Решение: «Сумма углов треугольника 180°, поэтому угол C = 180° − 60° − 80° = 40°. Ответ: 40°.»

Правильный ответ:
```json
{
  "canvas": {"width": 600, "height": 500, "margin": 40},
  "constructions": [
    {"type": "free_point", "id": "A", "x": 100, "y": 400},
    {"type": "free_point", "id": "B", "x": 500, "y": 400},
    {"type": "free_point", "id": "C", "x": 300, "y": 80},
    {"type": "triangle_arbitrary", "id": "tri_ABC", "p1": "A", "p2": "B", "p3": "C"}
  ],
  "aux": {"has_aux": false, "reason": "", "constructions": []}
}
```
Пояснение: только три точки и треугольник из условия. Никаких биссектрис/высот
из решения. Углы только в условии, но мы их не строим — только фигуру.

### Пример 2: Треугольник с высотой из условия

Условие: «В треугольнике ABC проведена высота BH. AB = 10, AH = 6. Найдите BH.»
Решение: «По теореме Пифагора BH = √(AB² − AH²) = √(100 − 36) = 8. Ответ: 8.»

Правильный ответ:
```json
{
  "canvas": {"width": 600, "height": 500, "margin": 40},
  "constructions": [
    {"type": "free_point", "id": "A", "x": 80, "y": 400},
    {"type": "free_point", "id": "C", "x": 520, "y": 400},
    {"type": "free_point", "id": "B", "x": 250, "y": 80},
    {"type": "segment", "id": "AC", "p1": "A", "p2": "C"},
    {"type": "line", "id": "l_AC", "p1": "A", "p2": "C"},
    {"type": "foot_perpendicular", "id": "H", "p1": "B", "line1": "l_AC"},
    {"type": "segment", "id": "AB", "p1": "A", "p2": "B"},
    {"type": "segment", "id": "BC", "p1": "B", "p2": "C"},
    {"type": "segment", "id": "BH", "p1": "B", "p2": "H", "dashed": false}
  ],
  "aux": {"has_aux": false, "reason": "", "constructions": []}
}
```
Пояснение: высота BH упомянута в условии — строим. Точка H упомянута — подписываем.

### Пример 3: Окружность и хорда — с доп. построением

Условие: «Дана окружность с центром O и радиусом 5. Хорда AB стягивает дугу 60°.
Найдите расстояние от центра до хорды.»
Решение: «Опустим перпендикуляр OM из центра O на хорду AB. OM — искомое расстояние.
В треугольнике OAM угол AOM = 30°, OA = 5. OM = OA·cos(30°) = 5·√3/2 ≈ 4.33. Ответ: 4.33.»

Правильный ответ:
```json
{
  "canvas": {"width": 600, "height": 500, "margin": 40},
  "constructions": [
    {"type": "free_point", "id": "O", "x": 300, "y": 250},
    {"type": "circle_center_radius", "id": "c_O", "center": "O", "radius": 120},
    {"type": "free_point", "id": "A", "x": 180, "y": 250},
    {"type": "free_point", "id": "B", "x": 420, "y": 250},
    {"type": "segment", "id": "AB", "p1": "A", "p2": "B"},
    {"type": "segment", "id": "OA", "p1": "O", "p2": "A"},
    {"type": "segment", "id": "OB", "p1": "O", "p2": "B"}
  ],
  "aux": {
    "has_aux": true,
    "reason": "Опущен перпендикуляр OM из центра на хорду AB",
    "constructions": [
      {"type": "line", "id": "l_AB", "p1": "A", "p2": "B"},
      {"type": "foot_perpendicular", "id": "M", "p1": "O", "line1": "l_AB"},
      {"type": "segment", "id": "OM", "p1": "O", "p2": "M", "dashed": true}
    ]
  }
}
```
Пояснение: базовый чертёж — окружность с хордой. Доп. построение — перпендикуляр OM
пунктиром (он нужен для решения, но не дан в условии).
