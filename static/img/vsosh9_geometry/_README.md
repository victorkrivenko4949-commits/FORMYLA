# FORMYLA · ВсОШ-9 · чертежи для геометрии (раздел F)

В этой папке лежат SVG-чертежи к задачам геометрических методов F1–F14.

## Имена файлов

Согласно ТЗ (`data/olympiads/roo_tz_geometry_diagrams_6_lines.md`):

    F{код}_{семейство}.{задача}_{номер_рисунка}.svg

Примеры:
- `F1_1.1_1.svg` — F1, семейство 1, задача 1.1, **только** один рисунок (исходная конфигурация).
- `F1_1.3_1.svg`, `F1_1.3_2.svg` — F1, семейство 1, задача 1.3, **два** рисунка:
  1. исходная конфигурация с подписями точек/углов/отрезков;
  2. дополнительное построение или подсветка ключевого хода решения.

Количество рисунков на задачу — из реестра
`data/olympiads/formyla_vsosh9_geometry_drawings_registry.md`.

## Стиль

Все SVG используют единый «премиальный тёмный» стиль FORMYLA.  Палитра
объявлена в блоке `<style>` прямо внутри каждого SVG, чтобы файл был
самодостаточным:

| Назначение | Цвет | Где используется |
|---|---|---|
| Фон | `#0B0E10` | `<rect class="bg">` подложка |
| Основные линии | `#E8E4D8` | стороны треугольников, прямые в условии |
| Подписи точек | `#E8E4D8` | `text.label` (A, B, C, …) |
| Углы / числа | `#D6C65A` (amber) | дуги углов, подписи градусов и длин |
| Доп. построение | `#12A7C8` (cyan) | биссектрисы, средние линии, перпендикуляры, отрезки, появляющиеся во 2-м рисунке |
