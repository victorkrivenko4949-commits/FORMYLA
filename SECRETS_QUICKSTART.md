## 🔧 Управление контентом

### Добавить статью вручную

```python
from app import app
from models import db, OlympiadSecret

with app.app_context():
    secret = OlympiadSecret(
        topic="Теория чисел",
        title="Новый метод",
        content="# Введение\n\nТекст с математикой \\( x^2 + y^2 = z^2 \\)",
        difficulty_level=2
    )
    db.session.add(secret)
    db.session.commit()
```

### Перегенерировать все статьи

```bash
python seed_secrets.py
# Выберите "yes" когда спросит про очистку базы
```

### Получить статьи через API

```bash
# Все статьи
curl http://localhost:5001/api/secrets

# По категории
curl http://localhost:5001/api/secrets?topic=Комбинаторика

# По сложности
curl http://localhost:5001/api/secrets?difficulty=2
```

## 📝 Правила форматирования LaTeX

### ✅ ПРАВИЛЬНО:

```markdown
Рассмотрим число \\( n = 2^k - 1 \\)

По теореме Ферма \\( a^{p-1} \\equiv 1 \\pmod{p} \\)

Блочная формула:
\\[ x^2 + y^2 = z^2 \\]
```

### ❌ НЕПРАВИЛЬНО:

```markdown
2³ = 8          (должно быть \\( 2^3 = 8 \\))
√2              (должно быть \\( \\sqrt{2} \\))
x² + y²         (должно быть \\( x^2 + y^2 \\))
```

## 🐛 Troubleshooting

### Проблема: "AssertionError: View function mapping is overwriting"

**Решение**: Старый код секретов был удалён из app.py. Перезапустите приложение.

### Проблема: Математика не рендерится

**Решение**: Проверьте, что в `base.html` подключены:
- `katex.min.css`
- `katex.min.js`
- `auto-render.min.js`
- `marked.min.js`

### Проблема: Статьи на английском

**Решение**: В `seed_secrets.py` системный промпт содержит "НА РУССКОМ ЯЗЫКЕ". Перегенерируйте контент.
