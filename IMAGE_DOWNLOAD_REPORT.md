### ❌ Что НЕ работает

1. **Автоматическое скачивание PDF с сайтов олимпиад**
   
   **Проблема:** Все попытки скачивания возвращают 404 или пустые результаты
   
   **Проверенные подходы:**
   - ✗ Прямые URL (formulo.org/data/2022/final/5.pdf) - 404
   - ✗ Парсинг HTML (BeautifulSoup) - нет ссылок на PDF
   - ✗ Playwright автоматизация - страницы не содержат PDF-ссылок
   
   **Причины:**
   - Сайты изменили структуру архивов
   - PDF размещены на внешних хостингах
   - Требуется авторизация или JavaScript
   - Материалы доступны только через интерактивные формы

2. **Качество текущих изображений**
   
   **Проблема:** Существующие картинки не соответствуют задачам
   
   **Пример:** Задача "Том и Джерри" (шестиугольное поле) показывает треугольник с кругом
   
   **Причина:** Изображения были созданы ранее вручную или взяты из других источников

## Проблема и решение

### Корневая проблема

**Сайты олимпиад не предоставляют публичный API или предсказуемые URL для скачивания PDF-архивов.**

### Возможные решения

#### Вариант 1: Ручное скачивание (рекомендуется)
1. Вручную скачайте PDF с официальных сайтов олимпиад
2. Положите в папку `temp_pdfs/`
3. Запустите `python scripts/extract_images.py`
4. Скрипт автоматически извлечет ВСЕ изображения и заменит текущие

#### Вариант 2: Selenium/Playwright с ручной навигацией
1. Используйте Playwright в интерактивном режиме
2. Вручную найдите страницы с PDF
3. Скрипт автоматически скачает найденные файлы

#### Вариант 3: Использовать текущие изображения
1. Текущие 377 изображений уже работают
2. Постепенно заменяйте неправильные на правильные
3. Для критичных задач создавайте чертежи вручную
