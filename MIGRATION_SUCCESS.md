## Технические детали

### База данных
- **Путь**: `instance/formyla.db`
- **Тип**: SQLite
- **Миграция**: Выполнена через `scripts/migrate_add_agent_type.py`

### Значения agent_type
- `algebra` - Агент по алгебре
- `geometry` - Агент по геометрии
- `number_theory` - Агент по теории чисел
- `combinatorics` - Агент по комбинаторике
- `movement` - Агент по задачам на движение
- `logic` - Агент по логике
- `mentor` - Агент-наставник
- `general` - Дефолтное значение (для старых записей)

### API изменения

#### GET /api/tutor/history
```
?agent_type=algebra
```
Возвращает историю только для выбранного агента.

#### POST /api/tutor/send
```json
{
  "message": "текст",
  "agent_type": "algebra",
  "hint_mode": true
}
```
Или с файлом (FormData):
```
message: "текст"
agent_type: "algebra"
hint_mode: "true"
file: <binary>
```

## Устранение проблем

### Если чат не работает
1. Проверьте, что Flask перезапущен
2. Проверьте консоль браузера (F12) на ошибки JavaScript
3. Проверьте логи Flask на ошибки Python

### Если изображения не работают
1. Убедитесь, что установлен `OPENROUTER_API_KEY` в `.env`
2. Проверьте, что файл правильно кодируется в Base64
3. Проверьте логи на ошибки API

### Если агенты не отказываются от чужих задач
1. Проверьте системные промпты в `ai/deepseek_client.py`
2. Убедитесь, что `agent_type` правильно передается
