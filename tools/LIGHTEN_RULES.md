# Правила облегчения решений каталога олимпиад

Файлы: `data/olymp_catalog/*.json`, список задач, поле `solution`.

## Кого трогаем
Только задачи, у которых:
- `solution` длиннее **1000 символов**;
- `status` НЕ в `{removed_by_user, broken_text, truncated_text, figure_only}`.

Остальные решения не трогаем вообще. Остальные поля задачи (`answer`, `text`,
`status`, `uid`, `source`, `fig_*`, …) не трогаем вообще — только `solution`.

## Что делать с решением
Цель: короткое, ясное решение школьником-олимпиадником, без воды.
1. Убрать вводные («Для решения задачи сначала поймём…»), служебное
   «Дано/Найти», нумерацию «Шаг 1/Шаг 2», самоповторы и пересказ условия.
2. Убрать хвосты критериев: «Критерии оценки…», «Только ответ — 0 баллов»,
   «Замечание. …» если оно не по сути решения.
3. Оставить математическую суть: идею, ключевые шаги, вывод. Ничего не
   «додумывать» и не менять сам ход рассуждения и ответ.
4. Целевая длина: примерно **треть–половина** исходного текста (но не короче
   60 символов и не длиннее исходного). Если решение уже плотное — можно
   оставить как есть или чуть подрезать.
5. Писать по-русски, живым текстом, без markdown (`###`, `**`, `__`, `---`).
   Абзацы — обычными пустыми строками.
6. Формулы — только в `\( ... \)` (inline) или `\[ ... \]` (выключка) либо
   `$ ... $`. Никакого голого LaTeX вне формул. Битый OCR-математический
   текст вида «R2√ 3 4» переписывать в нормальный LaTeX `\(R^2\frac{\sqrt3}{4}\)`.
7. Запрещённые команды KaTeX: `\tag` (в inline), `\-`, `\begin{itemize}` и т.п.
   `\begin{cases}`, `\begin{aligned}` — можно.

## Запрещено
- Менять смысл, числа, ответ, ход рассуждения.
- Менять любые поля кроме `solution`.
- Менять порядок задач, удалять/добавлять элементы списка.
- Коммитить в git (ветку и PR делает координатор).

## Проверка после правок
```
python3 tools/lighten_verify.py data/olymp_catalog/<ваш файл>.json
```
Должно вывести `ВСЁ ЧИСТО`. Если есть ошибки — исправить и перезапустить.
Катекс-часть запускается так (из корня репо, katex ставится: `npm i katex`):
```
NODE_PATH=/home/user/workspace/node_modules node tools/katex_check.js data/olymp_catalog/<файл>.json
```
