### Шаг 0. Запись в журнал

### Шаг 1. Снять блокеры PostgreSQL

Три места прямого `sqlite3` и `PRAGMA table_info` в боевом коде выполнятся
на SQLite и упадут на PostgreSQL. Починить каждое.

1. `routes/admin_support.py:78` — `PRAGMA table_info` заменить на
   `sqlalchemy.inspect(db.engine).get_columns('<таблица>')`. Результат
   привести к тому же виду, что ожидает вызывающий код.
2. `app.py:3156` — прямой `sqlite3.connect` заменить на SQLAlchemy-сессию
   либо на `db.session.execute(text(...))`.
3. `services/subscription.py:81` — то же самое.

После каждой правки — прогон `pytest -q --tb=line`. Числа не должны
ухудшиться против базовой линии шага 5 раздела «Что уже есть».

Если какое-то место починить нельзя без переписывания логики — не чинить,
а записать `ТРЕБУЕТ РЕШЕНИЯ ЧЕЛОВЕКА` с точной формулировкой и остановиться.
Выкладка с прямым `sqlite3` в боевом коде запрещена.

### Шаг 2. Проверить переносимость новых миграций

Для каждой миграции из пункта 7 раздела «Что уже есть» прочитать скрипт
и подтвердить построчно:

- `ALTER TABLE ... ADD COLUMN` без `DEFAULT` на NOT NULL колонке — на
  PostgreSQL упадёт, если таблица не пуста. На проде таблицы не пусты.
- `AUTOINCREMENT` — синтаксис SQLite. На PostgreSQL нужен `SERIAL`
  или `GENERATED BY DEFAULT AS IDENTITY`.
- `DATETIME` — на PostgreSQL `TIMESTAMP`.
- Склейка строк через `||` работает в обоих, через `+` — только в SQLite.
- `IF NOT EXISTS` в `CREATE TABLE` и `ADD COLUMN` — обязателен для
  идемпотентности.
- Кавычки в именах: SQLite принимает и одинарные, и двойные,
  PostgreSQL — только двойные для идентификаторов.

Для каждого найденного несовместимого места — починить в скрипте так,
чтобы он работал и на SQLite, и на PostgreSQL. Ветвление по диалекту
допускается: `db.engine.dialect.name == 'postgresql'`.

Прогнать каждый исправленный скрипт локально дважды подряд. Второй прогон
обязан пройти без ошибок и без дублирования — это доказательство
идемпотентности. Вывод обоих прогонов привести целиком.

5. Чек-лист переменных окружения для Render — только имена, значения

за рамки, pre-existing, не связано с нашими изменениями, ожидаемо,
выполняется, ожидается. Нет файла или функции — пишется ровно `NOT FOUND`.
