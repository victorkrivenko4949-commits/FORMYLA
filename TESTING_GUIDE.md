# 🧪 Руководство по тестированию новых функций

## Быстрый старт

### Предварительные требования

1. **Переменные окружения** (`.env`):
```env
SECRET_KEY=your-secret-key
DEEPSEEK_API_KEY=your-deepseek-api-key
MAIL_USERNAME=your-email@yandex.ru
MAIL_PASSWORD=your-password
```

2. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

3. **Запуск приложения:**
```bash
python app.py
```

## 📝 Тестирование бесплатного пробника

### Шаг 1: Открыть страницу пробников
```
http://localhost:5000/probniks
```

### Шаг 2: Нажать "Начать бесплатный пробник"
- Должна открыться страница `/free_mock/start`
- Видны формы выбора класса (4-11) и уровня

### Шаг 3: Выбрать параметры
- Выберите класс (например, 8)
- Выберите уровень (например, "Продвинутый")
- Нажмите "Сгенерировать мой вариант"

### Шаг 4: Дождаться генерации
- Процесс занимает 10-30 секунд
- DeepSeek API генерирует 25 задач
- При успехе перенаправит на `/free_mock/test`

### Шаг 5: Решить задачи
- Видны 5 блоков по 5 задач
- Заполните несколько ответов
- Проверьте прогресс-бар (правый нижний угол)
- Попробуйте обновить страницу (ответы должны сохраниться)

### Шаг 6: Отправить ответы
- Нажмите "Завершить тест"
- Подтвердите отправку
- Должна открыться страница результатов

### Шаг 7: Проверить результаты
- Видны баллы и процент правильных ответов
- Решения показаны **только для неправильных ответов**
- Статистика отображается корректно

## 🐛 Отладка проблем

### Проблема: DeepSeek API не работает

**Симптомы:**
- Ошибка "AI-генерация временно недоступна"
- Timeout при генерации

**Решение:**
1. Проверьте наличие `DEEPSEEK_API_KEY` в `.env`
2. Проверьте баланс API ключа
3. Проверьте интернет-соединение
4. Посмотрите логи Flask:
```python
print(f"🤖 Генерация 25 задач...")
print(f"❌ Ошибка DeepSeek API: {e}")
```

### Проблема: Задачи не генерируются

**Симптомы:**
- Ошибка "Ошибка обработки ответа AI"
- JSON parse error

**Решение:**
1. DeepSeek может вернуть markdown блоки
2. Код автоматически удаляет ```json и ```
3. Проверьте формат ответа в логах

### Проблема: Сессия истекла

**Симптомы:**
- "Сессия истекла. Создайте новый вариант"

**Решение:**
1. Проверьте `SECRET_KEY` в `.env`
2. Убедитесь, что он не меняется между перезапусками
3. Проверьте `session.permanent = True` в коде

### Проблема: Недостаточно задач для темы

**Симптомы:**
- "Недостаточно задач по теме"

**Решение:**
1. Проверьте `adaptive_data.py`
2. Убедитесь, что все JSON файлы загружены
3. Проверьте поле `subject` в задачах:
```python
python -c "from adaptive_data import ADAPTIVE_DB; print(set(p.get('subject') for p in ADAPTIVE_DB))"
```

## 🔍 Ручное тестирование API

### Тест генерации задач (curl)
```bash
curl -X POST http://localhost:5000/free_mock/generate \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grade=8&level=Продвинутый" \
  -c cookies.txt
```

### Тест адаптивного теста (curl)
```bash
curl -X GET "http://localhost:5000/adaptive_test/start?topic=algebra" \
  -c cookies.txt
```
