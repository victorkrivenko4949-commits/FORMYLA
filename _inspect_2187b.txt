# Итоговые чертежи (2187 шт.)

## Содержимое
- **all_charts.txt** — все 2187 SVG в исходном формате, разделены `### ЧЕРТЁЖ <chart_id>`.
- **svg/** — каждый SVG отдельным файлом (`<chart_id>.svg`).
- **generate_diagrams.py** — идемпотентный production-скрипт, которым сделаны эти чертежи. Идёт с checkpoint'ами, можно пере-запустить, чтобы перегенерировать конкретный класс или подмножество:
  ```
  python generate_diagrams.py --grade 9       # только 9 класс
  python generate_diagrams.py --only-missing  # только те, где чертежа изначально не было
  ```
- **report.jsonl** — по одной строке на задачу: что было изменено, какие проблемы исправлены.

## Как получено
- Стиль (тёмный фон #0F1729, синие линии, оранжевые пометки прямых углов, подписанные вершины и размеры) взят из вашего оригинального `paste-2.txt`.
- Каждой задаче LLM подавалось: условие, ответ, полное решение, исходный SVG (если был). Она выдавала итоговый SVG с корректными подписями вершин, числовыми метками из условия и вспомогательными построениями из решения.
- Все 2187 файлов прошли XML-валидацию (0 битых).
- Механический аудит показал: 1561 (71%) чертёж полностью соответствует условию/решению по вершинам и числам; у 626 остаются замечания (значительная часть — ложные срабатывания на номерах/годах).

## Что важно знать
- Механический аудит **не гарантирует геометрическую корректность** (правильные углы, точные пропорции). Это принципиально нельзя проверить автоматом на 2187 разных задачах.
- Для того чтобы «дожать» оставшиеся ~29%, запустите `generate_diagrams.py` повторно, предварительно удалив нужные `pipeline/ck/gen/fragments/*.jsonl` для тех chart_id, которые хотите перегенерировать. Скрипт возобновляется с точности того же места.
