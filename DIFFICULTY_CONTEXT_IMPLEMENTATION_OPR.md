## 4. Технические детали реализации

### 4.1 Архитектурное решение

**Паттерн:** Static Method в базовом классе + проброс контекста через промпт

**Преимущества:**
1. **Единая точка истины:** Все генераторы используют один и тот же маппинг
2. **Легкая модификация:** Изменение описаний в одном месте
3. **Типобезопасность:** Статический метод не требует инстанса
4. **Тестируемость:** Метод можно тестировать изолированно

### 4.2 Интеграция с LLM

**Механизм:**
1. Метод `get_difficulty_context(level)` возвращает детальное описание
2. Описание вставляется в user prompt как `ВНИМАНИЕ НА СЛОЖНОСТЬ: {context}`
3. System prompt усилен предупреждением о строгом соблюдении уровня
4. DeepSeek получает явные инструкции вместо абстрактной цифры

**Пример промпта для уровня 7:**
```
СЛОЖНОСТЬ: 7
ВНИМАНИЕ НА СЛОЖНОСТЬ: МАКСИМАЛЬНАЯ СЛОЖНОСТЬ (Заключительный этап Всероса). 
Экстремально сложная задача (хардкор). Искусственный синтез нескольких концепций 
(например, геометрия масс + графы) или сложная индукция. Решение требует гениальной догадки.
```
