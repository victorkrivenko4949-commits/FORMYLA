## 2. Failure Mode Analysis (Анализ точек отказа)

### 2.1 Точка отказа: Кеширование Python-модуля в памяти Flask

**Проблема:**  
Flask импортирует модуль `olympiads.py` при старте:
```python
from olympiads import OLYMPIADS_DB as _RAW_DB
```

Python кеширует импортированные модули в `sys.modules`. Изменения в файле не применяются до перезапуска процесса.

**Решение:**  
1. Остановка старого процесса через `taskkill /F /PID <PID>`
2. Запуск нового процесса `python app.py`
3. При старте Flask заново импортирует модуль с обновленными данными

**Статус:** ✅ Устранено

---

### 2.2 Точка отказа: Кеширование на фронтенде (браузер)

**Проблема:**  
Браузер может кешировать HTML-страницы с задачами, содержащие старый текст "(см. рисунок)".

**Решение:**  
Пользователю необходимо выполнить **жесткую перезагрузку страницы**:
- **Windows:** Ctrl+F5
- **Mac:** Cmd+Shift+R

**Статус:** ⚠️ Требуется действие пользователя

---

### 2.3 Точка отказа: Неполное удаление фразы

**Проблема:**  
Скрипт [`fix_see_figure.py`](fix_see_figure.py) мог пропустить вариации фразы с разными пробелами или переносами строк.

**Решение:**  
Скрипт обрабатывает следующие варианты:
```python
content = content.replace('(см. рисунок)', '')
content = content.replace('(см.\nрисунок)', '')
content = content.replace('(см.рисунок)', '')
content = content.replace('( см. рисунок )', '')
```

**Верификация:**  
```
Remaining instances of '(см. рисунок)': 0
Remaining instances of '(см.\nрисунок)': 0
```

**Статус:** ✅ Все вхождения удалены

### 2.4 Точка отказа: Ошибочное предположение о SQLite

**Проблема:**  
Первоначально предполагалось, что данные хранятся в SQLite базе данных [`formyla.db`](formyla.db) и требуется SQL-миграция.

**Анализ архитектуры:**
```python
# app.py:4
from olympiads import OLYMPIADS_DB as _RAW_DB

# app.py:112
COMBOS = _RAW_DB

# app.py:779-785
for c in COMBOS:
    if (c["olympiad"] == slug and ...):
        combo = c
```

**Вывод:**  
Данные загружаются из Python-файла в память, а не из SQLite. База данных используется только для:
- `User` (пользователи)
- `ChatMessage` (история чата с AI)
- `OAuthAccount` (OAuth-аккаунты)

**Решение:**  
Изменение данных в [`olympiads.py`](olympiads.py) + перезапуск Flask (без SQL-миграции).

**Статус:** ✅ Архитектура корректно определена
