# HuggingFace Dataset Import Workflow

## Обзор

Новая система импорта задач из профессиональных датасетов HuggingFace с автоматической классификацией через DeepSeek AI.

## Архитектура

```
HuggingFace Dataset (d0rj/ROMB-1.0)
         ↓
[scripts/hf_importer.py] - Загрузка + Классификация DeepSeek
         ↓
data/hf_problems.jsonl (промежуточный формат)
         ↓
[scripts/hf_migrator.py] - Конвертация в стандартный формат
         ↓
data/generated_problems.jsonl (стандартный формат)
         ↓
[scripts/migrator.py] - Миграция в базу
         ↓
problems.py (финальная база данных)
```

## Шаг 1: Импорт из HuggingFace

### Скрипт: `scripts/hf_importer.py`

**Что делает:**
- Загружает датасет d0rj/ROMB-1.0 (2552 задачи российских олимпиад)
- Классифицирует каждую задачу через DeepSeek AI:
  - Определяет класс (5-9)
  - Определяет раздел (Алгебра, Геометрия, и т.д.)
  - Выбирает подтему из списка 27 категорий
  - Оценивает сложность (1-5)
- Сохраняет в `data/hf_problems.jsonl`

**Запуск:**
```bash
python scripts/hf_importer.py
```

**Настройки:**
- `num_problems` - количество задач для обработки (по умолчанию 2500)
- `time.sleep(1)` - пауза между API запросами (защита от rate limit)
- Автосохранение каждые 50 задач

**Формат вывода (hf_problems.jsonl):**
```json
{
  "subject": "number_theory",
  "subtopic": "Делимость",
  "grade": 8,
  "difficulty": 2,
  "title": "Олимпиадная задача",
  "text": "Условие задачи...",
  "answer": "Ответ",
  "solution": "Решение...",
  "source": "HuggingFace",
  "source_dataset": "d0rj/ROMB-1.0"
}
```

## Шаг 2: Конвертация в стандартный формат

### Скрипт: `scripts/hf_migrator.py`

**Что делает:**
- Читает `data/hf_problems.jsonl`
- Конвертирует в формат, ожидаемый `migrator.py`:
  - Добавляет `subject_title` (русское название раздела)
  - Добавляет `subtopic_title` (уже есть от DeepSeek)
  - Добавляет `source_url` с информацией о датасете
- Сохраняет в `data/generated_problems.jsonl`
- Мигрирует в `problems.py` с автоматическим бэкапом

**Запуск:**
```bash
python scripts/hf_migrator.py
```

**Что происходит:**
1. Конвертация формата HF → стандартный
2. Валидация всех обязательных полей
3. Создание бэкапа `problems.py.bak`
4. Запись новой базы в `problems.py`
5. Верификация импорта

## Шаг 3: Использование на сайте

После миграции задачи автоматически доступны на сайте:

- **По разделам:** `/section/algebra`, `/section/geometry`, и т.д.
- **По подтемам:** `/subtopic/algebra/Уравнения`
- **По классам:** Фильтрация по grade
- **По сложности:** Фильтрация по difficulty

## Сравнение с парсингом HTML

### Старый подход (парсинг):
❌ Нестабильная структура HTML  
❌ Ломается при изменении сайта  
❌ Медленная обработка  
❌ Нужна ручная классификация  
❌ Проблемы с кодировкой  

### Новый подход (HuggingFace):
✅ Стабильный формат данных  
✅ Профессиональные датасеты  
✅ Автоматическая классификация AI  
✅ Быстрая загрузка  
✅ Чистые данные  
✅ 2500+ задач за один запуск

## Структура данных

### Обязательные поля в problems.py:
- `id` - уникальный ID (автоматически)
- `subject` - ключ раздела (algebra, geometry, и т.д.)
- `subject_title` - название раздела (Алгебра, Геометрия)
- `subtopic` - подтема (используется русское название)
- `subtopic_title` - название подтемы
- `grade` - класс (5-9)
- `difficulty` - сложность (1-5)
- `title` - заголовок задачи
- `text` - условие задачи
- `answer` - краткий ответ
- `solution` - подробное решение
- `source` - источник данных
- `source_url` - URL или описание источника

## Масштабирование

### Для обработки всех 2552 задач:
В `scripts/hf_importer.py` измените:
```python
num_problems = 2552  # Весь датасет
```

### Время обработки:
- ~3 секунды на задачу (с учетом API запроса)
- 2500 задач ≈ 2 часа
- Автосохранение каждые 50 задач (защита от сбоев)

### Мониторинг прогресса:
Скрипт выводит:
- `[N/2500] Processing problem...` - текущий прогресс
- `✓ Classification: {...}` - результат классификации
- `💾 Checkpoint: Saved N problems` - автосохранение

## Troubleshooting

### Ошибка: "DEEPSEEK_API_KEY not found"
Создайте файл `.env` с вашим API ключом:
```
DEEPSEEK_API_KEY=sk-your-key-here
```

### Ошибка: Rate Limit
Увеличьте паузу между запросами:
```python
time.sleep(2)  # Вместо 1 секунды
```

### Ошибка: Dataset not found
Проверьте интернет-соединение и доступность HuggingFace.

### Прерванная обработка
Скрипт сохраняет прогресс каждые 50 задач. Просто запустите снова - новые задачи добавятся к существующим.
