# 🤖 Адаптивный тест с AI-проверкой

## Обзор

Реализован двухэтапный флоу адаптивного тестирования с умной проверкой ответов через DeepSeek AI.

## Архитектура

### Backend (app.py)

#### Новый API endpoint: `/api/check_adaptive_answer`

**Метод:** POST  
**Content-Type:** application/json

**Входные данные:**
```json
{
  "task_id": "90001",
  "user_answer": "42",
  "user_solution": "Решал через формулу..."
}
```

**Выходные данные:**
```json
{
  "status": "success",
  "score": 2,
  "feedback": "Отлично! Решение верное...",
  "new_level": 5,
  "is_last_task": false,
  "current_index": 3
}
```

**Логика работы:**

1. Проверяет наличие активной сессии теста
2. Находит задачу в БД по `task_id`
3. Формирует промпт для DeepSeek AI:
   - Условие задачи
   - Правильный ответ
   - Ответ ученика
   - Решение ученика
4. Получает от AI оценку в формате JSON:
   - `score: 2` — идеальное решение (+2 уровня)
   - `score: 1` — частично верно (+1 уровень)
   - `score: -1` — неверно (-1 уровень)
5. Обновляет `session['adaptive_current_difficulty']` (диапазон 1-7)
6. Сохраняет результат в `session['adaptive_answers']`
7. Возвращает JSON с результатом

**Fallback:** Если DeepSeek недоступен, возвращает нейтральную оценку (score=1).

### Frontend (adaptive_test_simple.html)

#### Изменения в форме

- Форма больше не отправляется стандартным способом
- JavaScript перехватывает событие `submit` через `e.preventDefault()`
- Данные отправляются через `fetch` API

#### Новые UI-компоненты

1. **Лоадер AI-проверки** (`#aiLoader`)
   - Показывается во время проверки
   - Анимированный спиннер
   - Текст: "🤖 AI проверяет ваше решение..."

2. **Блок результата** (`#resultBlock`)
   - Вердикт (✅/⚠️/❌) с цветовой индикацией
   - Новый уровень сложности
   - Фидбек от AI-тьютора
   - Кнопки: "Следующая задача" / "Завершить тест"

#### JavaScript-функции

- `showLoader()` — показывает лоадер, скрывает форму
- `hideLoader()` — скрывает лоадер
- `showResult(result)` — отображает результат проверки
- `goToNextTask()` — переход к следующей задаче
- `finishTest()` — завершение теста

### Страница результатов (adaptive_test_simple_results.html)

**Новый шаблон** с детальным разбором:

- Общая статистика (точность, решено задач, финальный уровень)
- Детальный разбор каждой задачи:
  - Оценка AI (score)
  - Ответ пользователя
  - Правильный ответ
  - Фидбек от AI-тьютора
  - Решение пользователя (под спойлером)
- Персонализированные рекомендации
- Кнопки действий (пройти заново, выбрать другую тему)

## User Journey

1. **Пользователь видит задачу** → вводит ответ и решение
2. **Нажимает "Ответить"** → форма НЕ отправляется, срабатывает JS
3. **Показывается лоадер** → "🤖 AI проверяет ваше решение..."
4. **AJAX-запрос на `/api/check_adaptive_answer`** → DeepSeek анализирует (5-10 сек)
5. **Получен ответ** → лоадер скрывается
6. **Показывается результат:**
   - Вердикт (✅ Верно! +2 уровня / ⚠️ Частично верно. +1 уровень / ❌ Неверно. -1 уровень)
   - Новый уровень сложности
   - Разбор от AI-тьютора
7. **Пользователь читает фидбек** → нажимает "Следующая задача"
8. **Страница перезагружается** → загружается задача нового уровня
9. **Повторяется 25 раз** → на 25-й задаче показывается "Завершить тест"
10. **Страница результатов** → детальный разбор всех задач с фидбеком AI

## Технические детали

### Обработка ошибок

- Если DeepSeek API недоступен → fallback на простую проверку
- Если JSON от AI невалидный → используется regex для извлечения или весь ответ как feedback
- Если сессия истекла → возвращается ошибка 400

### Безопасность

- Проверка наличия активной сессии
- Валидация входных данных (task_id, user_answer)
- Ограничение длины feedback (500 символов при fallback)

### Производительность

- Timeout для DeepSeek API: 90 секунд
- Max tokens: 1000 (для экономии)
- Temperature: 0.3 (для стабильности оценок)

## Интеграция с существующей системой

### Обратная совместимость

- Старый endpoint `/adaptive_test_simple/submit` остается как fallback
- Поддержка старого формата данных (`is_correct`) в статистике
- Новый формат (`score`) имеет приоритет

### База данных

- Результаты сохраняются в `AdaptiveTestResult`
- Обновляется `UserTopicProgress`
- Обновляется общая статистика пользователя

## Конфигурация

### Переменные окружения

- `DEEPSEEK_API_KEY` — ключ API DeepSeek (обязательно)

```
{
  "score": X,
  "feedback": "текст разбора"
}

- 2 (идеальное решение, правильный ответ)

```
