# Подключение LiveKit Cloud для группового звонка на доске

Файлы уже залиты в проект. Чтобы кнопка **👥 Групповой звонок** в `/drawing` заработала, нужно только подключить аккаунт LiveKit Cloud (бесплатный тариф) и положить 3 переменные окружения на Render.

## Шаг 1. Регистрация на cloud.livekit.io (≈ 3 минуты)

1. Открыть **https://cloud.livekit.io** → **Get started for free**.
2. Авторизация через GitHub / Google. Карту вводить не нужно — есть free tier (10 000 минут участников / месяц).
3. После входа автоматически создаётся **первый проект**. Можно переименовать, например `formyla-prod`.

## Шаг 2. Получить три ключа

В дашборде проекта:

1. Слева в меню → **Settings** → **Keys** (или сразу секция «API Keys» на главной).
2. Нажать **Create new key** (или скопировать дефолтный).
3. Выписать три значения:

| Переменная | Где взять | Пример |
|---|---|---|
| `LIVEKIT_URL` | На главной проекта, поле **Project URL** | `wss://formyla-prod-abc123.livekit.cloud` |
| `LIVEKIT_API_KEY` | Settings → Keys → **Key** | `APIabc123xyz...` |
| `LIVEKIT_API_SECRET` | Settings → Keys → **Secret** (показывается один раз) | `0123456789abcdef...` |

> ⚠️ **Secret показывается только при создании ключа.** Если потерял — создавай новый ключ и удаляй старый.

## Шаг 3. Положить переменные на Render

1. Зайти в **Render Dashboard** → выбрать сервис **FORMYLA** (Web Service).
2. **Environment** → **Add Environment Variable**.
3. Добавить ровно три записи (без кавычек):

   ```
   LIVEKIT_URL          = wss://...livekit.cloud
   LIVEKIT_API_KEY      = APIabc123...
   LIVEKIT_API_SECRET   = 0123456789abcdef...
   ```

4. Render перезапустит сервис автоматически (≈ 60 секунд).

## Шаг 4. Проверка

1. Открой `/drawing` → вкладка **🎨 Доска**.
2. В правом верхнем углу должна быть **зелёная кнопка 👥** (рядом с фиолетовой 📹 для 1-на-1).
3. Кликни → введи имя и код комнаты (например `math-42`) → **Войти**.
4. Браузер попросит доступ к камере и микрофону → разреши.
5. На другом устройстве/вкладке зайди на тот же `/drawing?meet=math-42` (или вручную введи тот же код) — вы должны увидеть друг друга.

### Если кнопка пишет «⚠ Сервер ещё не подключён к LiveKit Cloud»

Значит env-переменные не подхватились. Проверить так:

```bash
curl https://<твой-домен>/api/wb_meet/config
```

Должно вернуть `{"enabled": true, "url": "wss://...", "max": 10, "token_ttl_seconds": 3600}`.
Если `enabled: false` — переменные на Render не сохранились, или сервис ещё перезапускается.

## Архитектура

- `routes/wb_meet.py` — Flask blueprint, выдаёт **только JWT-токены** (1 час TTL).
- Сама аудио/видео-связь идёт **напрямую браузер ⟷ LiveKit SFU**, через наш сервер не проходит, нагрузки/трафика на Render почти не добавляет.
- На клиенте — `static/js/wb_meet.js`, грузит `livekit-client` с CDN (`jsdelivr`) лениво, при первом клике на кнопку. Без npm/build-step.
- Локальный счётчик участников (макс. 10) в памяти процесса. LiveKit Cloud free tier общий лимит — 10 000 participant-minutes / месяц, этого хватает на ≈ 16 часов 10-местных звонков.

## Что считается «participant-minute»?

Один человек в комнате 1 минуту = 1 participant-minute. Звонок 5 человек × 30 минут = 150 minutes.

Бесплатный тариф достаточен для тестов и индивидуальных репетиторов. Если перерасходуешь, LiveKit пишет письмо и предлагает апгрейд (~$50/мес за 50k minutes).

## Откат

Если хочешь отключить групповые звонки:

1. Просто удали `LIVEKIT_URL` (или один из трёх ключей) из Environment на Render.
2. `/api/wb_meet/config` начнёт возвращать `enabled: false`, кнопка скажет «⚠ Сервер не подключён».
3. Кнопка `📹` (1-на-1) продолжает работать независимо.

Никаких миграций БД и удаления файлов не требуется.
