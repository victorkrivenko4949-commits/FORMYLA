# 📝 Бесплатный пробник и адаптивное тестирование

## Обзор реализованных функций

Этот документ описывает две основные системы тестирования в FORMYLA:

1. **Бесплатный пробник** - 25 задач, сгенерированных через DeepSeek AI
2. **Адаптивный тест** - тестирование с фильтрацией по темам и AI-проверкой решений

---

## 🎯 ЗАДАЧА 1: Бесплатный тест (25 задач через DeepSeek AI)

### Архитектура

```
/probniks → /free_mock/start → /free_mock/generate → /free_mock/test → /free_mock/submit → результаты
```

### Реализованные маршруты

#### 1. `GET /free_mock/start`
**Файл:** `app.py` (строка ~1680)  
**Шаблон:** `templates/free_mock_setup.html`

Показывает страницу настройки теста с выбором:
- Класса (4-11)
- Уровня сложности (Базовый/Продвинутый/Олимпиадный)

#### 2. `POST /free_mock/generate`
**Файл:** `app.py` (строка ~1706)

Генерирует 25 задач через DeepSeek API:
- Использует `DeepSeekClient` из `ai/deepseek_client.py`
- Промпт запрашивает JSON массив с полями: `id`, `text`, `answer`, `solution`, `difficulty`
- Сохраняет задачи в `session['free_mock_tasks']`
- Обрабатывает ошибки API и парсинга JSON

**Пример промпта:**
```python
f"""Сгенерируй 25 математических задач для {grade} класса, уровень "{level}".

Требования:
- Разнообразные темы: алгебра, геометрия, текстовые задачи, логика
- 5 блоков по 5 задач с возрастающей сложностью внутри блока
- Каждая задача должна иметь короткий числовой или текстовый ответ
- Обязательно укажи полное решение для каждой задачи

Верни ТОЛЬКО валидный JSON массив...
"""
```

#### 3. `GET /free_mock/test`
**Файл:** `app.py` (строка ~1792)  
**Шаблон:** `templates/free_mock_test.html`

Отображает 25 задач в 5 блоках по 5 задач:
- Поля для ввода ответов (без решений!)
- Прогресс-бар заполнения
- Автосохранение в localStorage
- Подтверждение перед отправкой

**Особенности UI:**
- Блочная структура (5 блоков)
- Индикатор прогресса (фиксированный в правом нижнем углу)
- Автосохранение ответов в localStorage
- Валидация перед отправкой

#### 4. `POST /free_mock/submit`
**Файл:** `app.py` (строка ~1811)  
**Шаблон:** `templates/free_mock_results.html`

Проверяет ответы и показывает результаты:
- Нормализация ответов (lowercase, удаление пробелов, замена запятой на точку)
- Подсчет баллов
- **Решения показываются только для неправильных ответов**
- Статистика и рекомендации

## 🎯 ЗАДАЧА 2: Адаптивный тест (6 тем, AI-проверка)

### Доступные темы

Из `ADAPTIVE_DB` (480 задач):
- `algebra` - Алгебра (80 задач)
- `geometry` - Геометрия (80 задач)
- `combinatorics` - Комбинаторика (80 задач)
- `number_theory` - Теория чисел (80 задач)
- `movement` - Задачи на движение (160 задач)
- `knights_liars` - Рыцари и лжецы (часть movement)

### Реализованные маршруты

#### 1. `GET /adaptive_test/start?topic=<topic>`
**Файл:** `app.py` (строка ~1869)

Запускает адаптивный тест с фильтрацией по теме:
- Фильтрует `ADAPTIVE_DB` по полю `subject`
- Сохраняет отфильтрованные задачи в сессию
- Устанавливает начальную сложность = 3
- Перенаправляет на страницу пробников с уведомлением

**Пример использования:**
```html
<a href="/adaptive_test/start?topic=algebra">Алгебра</a>
<a href="/adaptive_test/start?topic=geometry">Геометрия</a>
```

#### 2. Существующие API маршруты

Адаптивное тестирование уже имеет полную реализацию:

- `POST /api/adaptive-test/start` - Создание теста в БД
- `POST /api/adaptive-test/<id>/submit` - Отправка ответа
- `POST /api/adaptive-test/<id>/analyze` - AI-анализ результатов
- `GET /adaptive-test/<id>` - Страница теста
- `GET /adaptive-test/<id>/results` - Результаты

### AI-проверка решений

**Файл:** `app.py` (строка ~2111)

Функция `analyze_adaptive_test()` использует DeepSeek для:
- Анализа сильных и слабых сторон
- Персональных рекомендаций
- Определения олимпиадного статуса
- Советов по подготовке

**Алгоритм адаптации:**
- Правильный ответ: сложность +2
- Частично правильный: сложность +1
- Неправильный: сложность -2

## 🚀 Использование

### Бесплатный пробник

1. Пользователь заходит на `/probniks`
2. Нажимает "Начать бесплатный пробник"
3. Выбирает класс и уровень
4. Нажимает "Сгенерировать мой вариант"
5. DeepSeek генерирует 25 задач (~10-30 секунд)
6. Решает задачи в своем темпе
7. Отправляет ответы
8. Видит результаты с решениями для ошибок

### Адаптивный тест

1. Пользователь заходит на `/probniks`
2. Выбирает тему (Алгебра, Геометрия и т.д.)
3. Система фильтрует задачи по теме
4. Запускается адаптивный алгоритм
5. После каждого ответа сложность адаптируется
6. После 25 задач - AI-анализ результатов

## 🔧 Технические детали

### DeepSeek API

**Конфигурация:**
- Model: `deepseek-chat`
- Temperature: 0.7 (для генерации задач)
- Max tokens: 8000
- Retry logic: 5 попыток с экспоненциальной задержкой

**Обработка ошибок:**
- `DeepSeekAPIError` - ошибки API
- `json.JSONDecodeError` - ошибки парсинга
- Fallback на уведомление пользователя

### Сессии

Данные хранятся в Flask session:
```python
session['free_mock_tasks']      # Список задач
session['free_mock_grade']      # Класс
session['free_mock_level']      # Уровень
session['adaptive_topic']       # Тема адаптивного теста
session['adaptive_filtered_tasks']  # ID отфильтрованных задач
```

### База данных ADAPTIVE_DB

**Источник:** `adaptive_data.py`  
**Формат задачи:**
```python
{
    'id': 90001,
    'text': 'Текст задачи',
    'answer': 'Ответ',
    'solution': 'Решение',
    'difficulty': 3,
    'subject': 'algebra',
    'grade': 8
}
```

## 🐛 Известные ограничения

1. **DeepSeek API:**
   - Требует активный API ключ
   - Генерация может занять 10-30 секунд
   - Возможны rate limits

2. **Бесплатный пробник:**
   - Задачи не сохраняются в БД
   - Нет истории прохождений
   - Только проверка ответов (не решений)

3. **Адаптивный тест:**
   - Требует авторизации
   - Использует существующую БД модель
   - Зависит от `services/adaptive_test.py`
