# 🎯 AI-Онбординг для новых пользователей

## Описание фичи

Умный AI-онбординг, который анализирует математический опыт пользователя и дает персональные рекомендации.

## 🚀 Как работает

### 1. Пользователь заходит на `/onboarding`

Видит красивую форму с приглашением рассказать о своем опыте:
- Участие в олимпиадах
- Сильные и слабые темы
- Класс и уровень подготовки
- Цели обучения

### 2. AI анализирует текст

После отправки формы:
- Показывается красивый лоадер
- Текст отправляется в DeepSeek API
- AI анализирует опыт и определяет уровень

### 3. Персональный отчет

Пользователь получает:
- **Уровень:** beginner / intermediate / advanced
- **Персональный отчет:** мотивирующий текст от AI-тренера (2-3 абзаца)
- **Рекомендуемые темы:** 2-3 темы для фокуса
- **Кнопка:** "Перейти к моим первым задачам"

## 📁 Файлы

### Backend

**[`ai/deepseek_client.py`](../ai/deepseek_client.py)**
- Метод `analyze_user_background(user_text)` - анализ через DeepSeek API
- Возвращает JSON с level, report, recommended_topics

**[`app.py`](../app.py)**
- `GET /onboarding` - страница онбординга
- `POST /api/onboarding` - API для анализа текста
- Сохранение результатов в session

### Frontend

**[`templates/onboarding.html`](../templates/onboarding.html)**
- Красивая форма с textarea
- Лоадер с анимацией
- Результаты с бейджами и отчетом
- Адаптивный дизайн

## 🔧 Технические детали

### API Endpoint

**POST /api/onboarding**

Request:
```json
{
  "text": "Я учусь в 9 классе, участвовал в школьных олимпиадах..."
}
```

Response:
```json
{
  "level": "intermediate",
  "report": "Отлично! Вижу, что у тебя уже есть опыт...",
  "recommended_topics": ["algebra", "geometry", "combinatorics"]
}
```

### Session данные

После анализа сохраняются:
- `onboarding_completed`: true
- `math_level`: beginner/intermediate/advanced
- `recommended_topics`: список тем

## 🎯 Использование

1. Пользователь регистрируется
2. Перенаправляется на `/onboarding`
3. Заполняет форму
4. Получает персональные рекомендации
5. Переходит к задачам
