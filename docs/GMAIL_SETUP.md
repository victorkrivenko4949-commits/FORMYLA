# 📧 Настройка Gmail для отправки кодов авторизации

## 🎯 Быстрая инструкция (3 шага)

### Шаг 1: Создайте App Password в Google

1. Откройте: https://myaccount.google.com/apppasswords
2. Войдите в свой Google аккаунт (если нужно)
3. Нажмите **"Создать"** или **"Generate"**
4. Введите название: **"FORMYLA"**
5. Нажмите **"Создать"**
6. **Скопируйте** 16-значный пароль (формат: `xxxx xxxx xxxx xxxx`)

⚠️ **Важно:** Если у вас нет доступа к App Passwords, включите двухфакторную аутентификацию (2FA) в настройках Google аккаунта.

### Шаг 2: Добавьте данные в файл `.env`

Откройте файл `.env` в корне проекта и добавьте:

```env
# Email Configuration
MAIL_USERNAME=ваш_email@gmail.com
MAIL_PASSWORD=xxxx xxxx xxxx xxxx
```

**Замените:**
- `ваш_email@gmail.com` → ваш реальный Gmail
- `xxxx xxxx xxxx xxxx` → скопированный App Password

### Шаг 3: Перезапустите сервер

```bash
python app.py
```

Готово! Теперь коды будут отправляться на реальную почту.

## 📋 Подробная инструкция

### Требования

- ✅ Gmail аккаунт
- ✅ Двухфакторная аутентификация (2FA) включена

### Включение 2FA (если еще не включена)

1. Откройте: https://myaccount.google.com/security
2. Найдите раздел **"Двухэтапная аутентификация"**
3. Нажмите **"Начать"**
4. Следуйте инструкциям Google

### Создание App Password

1. **Откройте:** https://myaccount.google.com/apppasswords
   
2. **Войдите** в аккаунт (если требуется)

3. **Создайте пароль:**
   - Нажмите "Создать" или "Generate"
   - Введите название: "FORMYLA" (или любое другое)
   - Нажмите "Создать"

4. **Скопируйте пароль:**
   - Google покажет 16-значный пароль
   - Формат: `abcd efgh ijkl mnop`
   - **Скопируйте его** (показывается только один раз!)

5. **Нажмите "Готово"**

### Настройка .env файла

Откройте файл `.env` в корне проекта:

```env
# Email Configuration (Gmail SMTP for passwordless auth)
MAIL_USERNAME=your_email@gmail.com
MAIL_PASSWORD=abcd efgh ijkl mnop
```

**Важно:**
- Используйте **App Password**, НЕ обычный пароль от Gmail
- Пробелы в App Password можно оставить или убрать (работает и так, и так)
- Не делитесь этим паролем!

### Проверка настройки

1. Перезапустите сервер: `python app.py`
2. Откройте: http://127.0.0.1:5000/login
3. Введите свой email
4. Нажмите "Получить код"
5. Проверьте почту - должно прийти письмо с кодом!

## 🔧 Troubleshooting

### Ошибка: "Username and Password not accepted"

**Причина:** Используется обычный пароль вместо App Password

**Решение:** Создайте App Password по инструкции выше

### Ошибка: "App Passwords недоступны"

**Причина:** Не включена двухфакторная аутентификация

**Решение:** Включите 2FA в настройках Google

### Письмо не приходит

**Проверьте:**
1. Правильность email в MAIL_USERNAME
2. Правильность App Password в MAIL_PASSWORD
3. Папку "Спам" в почте
4. Консоль сервера - там будут ошибки если что-то не так

### Для разработки без email

Если не хотите настраивать email, код будет выводиться в консоль при ошибке отправки.
