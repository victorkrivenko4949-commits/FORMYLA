# Раздел "Секреты олимпиадной математики"

## Описание

База знаний мощных олимпиадных методов, лайфхаков и теории для подготовки к математическим олимпиадам.

## Архитектура

### База данных

**Модель: `OlympiadSecret`** (файл: `models.py`)

Поля:
- `id` - первичный ключ
- `topic` - категория (Теория чисел, Комбинаторика, Алгебра, Геометрия, Логика, Графы)
- `title` - название метода/секрета
- `content` - текст статьи в Markdown с LaTeX математикой
- `difficulty_level` - уровень сложности (1-3)
- `created_at` - дата создания

### Backend (Flask)

**Файл: `app.py`**

Маршруты:
- `GET /secrets` - главная страница раздела с фильтром по категориям
- `GET /secrets/<id>` - страница отдельной статьи
- `GET /api/secrets` - API для получения списка секретов (JSON)

### Frontend

**Шаблоны:**
- `templates/secrets.html` - список статей с фильтром по категориям
- `templates/secret_detail.html` - страница отдельной статьи с рендерингом Markdown и KaTeX

**Особенности рендеринга:**
- Markdown рендерится через `marked.js`
- Математика рендерится через `KaTeX` с поддержкой `\( ... \)` и `\[ ... \]`
- Адаптивная сетка карточек статей
- Индикаторы сложности (1-3 звезды)

2. **Комбинаторика** (4 статьи): Принцип Дирихле, Метод шаров и перегородок, Принцип включений-исключений, Рекуррентные соотношения
3. **Алгебра** (4 статьи): Неравенство Коши, Метод замены переменных, Теорема Виета, Метод мажорант

6. **Графы** (3 статьи): Основы теории графов, Эйлеровы и Гамильтоновы пути, Деревья и их свойства

### Системный промпт для генерации

**КРИТИЧЕСКИ ВАЖНО:** Все статьи генерируются на **РУССКОМ ЯЗЫКЕ** для русскоязычной аудитории.

Промпт обеспечивает:
- Структуру: Введение → Базовый пример → Олимпиадная задача
- Правильное форматирование LaTeX: `\( ... \)` для инлайн, `\[ ... \]` для блоков
- Запрет на юникод-символы (², ³, √) - только LaTeX
- Строгое использование `^` и `_` для степеней и индексов

## Использование

### Для пользователей

1. Перейти на страницу `/secrets`
2. Выбрать интересующую категорию (или "Все темы")
3. Кликнуть на карточку статьи
4. Читать статью с правильно отрендеренной математикой

### Для разработчиков

**Добавление новых статей вручную:**

```python
from app import app
from models import db, OlympiadSecret

with app.app_context():
    secret = OlympiadSecret(
        topic="Теория чисел",
        title="Новый метод",
        content="# Введение\n\nТекст с математикой \\( x^2 + y^2 = z^2 \\)",
        difficulty_level=2
    )
    db.session.add(secret)
    db.session.commit()
```

**Получение статей через API:**

```bash
# Все статьи
curl http://localhost:5000/api/secrets

# Фильтр по категории
curl http://localhost:5000/api/secrets?topic=Комбинаторика

# Фильтр по сложности
curl http://localhost:5000/api/secrets?difficulty=2
```

## Правила форматирования LaTeX

### ✅ ПРАВИЛЬНО:

```markdown
Рассмотрим число \\( n = 2^k - 1 \\)

По теореме Ферма \\( a^{p-1} \\equiv 1 \\pmod{p} \\)

Неравенство \\( \\frac{a+b}{2} \\geq \\sqrt{ab} \\)

Блочная формула:
\\[ x^2 + y^2 = z^2 \\]
```

### ❌ НЕПРАВИЛЬНО:

```markdown
2³ = 8          (должно быть \\( 2^3 = 8 \\))
√2              (должно быть \\( \\sqrt{2} \\))
x² + y²         (должно быть \\( x^2 + y^2 \\))
```

## Troubleshooting

### Проблема: Математика не рендерится

**Решение:** Проверьте, что в `base.html` подключены:
- `katex.min.css`
- `katex.min.js`
- `auto-render.min.js`
- `marked.min.js`

### Проблема: Статьи на английском языке

**Решение:** 
1. Убедитесь, что в `seed_secrets.py` системный промпт содержит "НА РУССКОМ ЯЗЫКЕ"
2. Очистите базу: запустите `seed_secrets.py` и выберите "yes" для очистки
3. Перегенерируйте контент

### Проблема: Юникод-символы вместо LaTeX

**Решение:**
1. Проверьте системный промпт в `seed_secrets.py`
2. Убедитесь, что там есть запрет на юникод-символы
3. Перегенерируйте статьи
