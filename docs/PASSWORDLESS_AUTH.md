# 🔐 Passwordless авторизация

## Концепция

Беспарольная авторизация по email с 6-значным кодом и долгоживущими cookie (30 дней).

## 🔄 Флоу авторизации

### Шаг 1: Ввод email
**URL:** `/login`

1. Пользователь вводит только email
2. Система генерирует 6-значный код
3. Код сохраняется в БД (действителен 10 минут)
4. Код выводится в консоль сервера (для теста)
5. Редирект на `/verify-code`

### Шаг 2: Проверка кода
**URL:** `/verify-code`

1. Пользователь вводит 6-значный код
2. Система проверяет код и срок действия
3. При успехе:
   - Авторизация через Flask-Login
   - Cookie на 30 дней (remember=True)
   - Очистка кода из БД
   - Редирект на `/onboarding` (если не пройден) или главную

## 📁 Файлы

### Backend

**[`models.py`](../models.py)**
- Поля: `email`, `auth_code`, `code_expires`
- Методы: `generate_auth_code()`, `verify_auth_code()`, `clear_auth_code()`

**[`app.py`](../app.py)**
- `POST /login` - генерация кода
- `GET/POST /verify-code` - проверка кода
- `GET /logout` - выход
- Конфигурация cookie: 30 дней

### Frontend

**[`templates/login.html`](../templates/login.html)**
- Минималистичная форма: только email
- Кнопка "Получить код"

**[`templates/verify_code.html`](../templates/verify_code.html)**
- Поле для 6-значного кода
- Крупный шрифт, моноширинный
- Таймер: "Код действителен 10 минут"

## 🔧 Технические детали

### Генерация кода

```python
import random
code = ''.join([str(random.randint(0, 9)) for _ in range(6)])
```

### Срок действия

- **Код:** 10 минут
- **Cookie:** 30 дней

### Безопасность

- ✅ Код хранится в БД, не в сессии
- ✅ Проверка срока действия
- ✅ Очистка кода после использования
- ✅ HttpOnly cookie
- ✅ SameSite=Lax

## 🧪 Тестирование

1. Откройте: http://127.0.0.1:5000/login
2. Введите email (любой)
3. Нажмите "Получить код"
4. Проверьте консоль сервера - там будет код
5. Введите код на странице `/verify-code`
6. Вы авторизованы на 30 дней!

## 📊 Преимущества

✅ Нет паролей - проще для пользователей  
✅ Безопасно - коды одноразовые и временные  
✅ Удобно - cookie на 30 дней  
✅ Быстро - не нужно придумывать пароль
