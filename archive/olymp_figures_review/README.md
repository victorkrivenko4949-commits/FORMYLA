# Архив проверки рисунков FORMYLA

Здесь сохранены 191 непривязанный файл и прежние версии заменённых или исключённых изображений. Они находятся вне `static/olymp_figures`, поэтому не считаются действующими иллюстрациями и не прикрепляются к карточкам автоматически.

## Восстановление и проверка

- **manifest.json**: исходный путь, причина переноса, SHA-256, путь к архивному объекту и коммит исходной версии.
- **objects/**: исходные байты без перекодирования; одинаковые объекты сохранены один раз.
- **Восстановление**: скопировать соответствующий объект в исходный путь из манифеста. Привязку к задаче следует восстанавливать только после проверки её первоисточника.

Все 191 непривязанный файл просмотрены на контактных листах. Среди них есть полноценные чертежи, повторяющиеся изображения и старые SVG-построения с ненадёжными привязками; само наличие подходящей геометрии не доказывает соответствие конкретной задаче.

Ни один файл не прикреплён к новой задаче только по имени, визуальному сходству или близости UID. Отсутствие надёжного однозначного соответствия означает архивирование, а не признание изображения ошибочным.

Команды из корня репозитория:

```sh
python scripts/olymp_figs_validate.py
python scripts/olymp_figs_quarantine.py
```

Вторая команда по умолчанию ничего не изменяет. Для повторного архивирования нужен `--apply`, а для сохранения прежних версий требуется история Git до коммита, указанного в манифесте.
