# Справочник построений Geometric Engine

Каждое построение описывается объектом JSON с полями `type` и `id`.
Все координаты — в пикселях холста. Все ссылки — по `id` ранее определённых объектов.

---

## ТОЧКИ

### `free_point` — Свободная точка
Задаётся явными координатами (x, y) на холсте.

| Параметр | Тип | Описание |
|----------|-----|----------|
| x | number | Координата X |
| y | number | Координата Y |

```json
{"type": "free_point", "id": "A", "x": 100, "y": 200}
```

---

### `midpoint` — Середина отрезка
Строит точку ровно посередине между двумя заданными точками.

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id первой точки отрезка |
| p2 | string | id второй точки отрезка |

```json
{"type": "midpoint", "id": "M", "p1": "A", "p2": "B"}
```

---

### `point_on_segment` — Точка на отрезке в заданном отношении
Делит отрезок AB в отношении t : (1-t).

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id точки A (t=0) |
| p2 | string | id точки B (t=1) |
| ratio | number | Отношение 0..1, по умолчанию 0.5 |

```json
{"type": "point_on_segment", "id": "P", "p1": "A", "p2": "B", "ratio": 0.3}
```

---

### `point_on_circle` — Точка строго на окружности (CH26)

Размещает точку точно на окружности (center + R·(cos t, sin t)).
Либо по явному углу `angle_deg`, либо на дуге `between: [X, Y]`
(детерминированно от seed, строго внутри дуги, не совпадая с границами).

| Параметр | Тип | Описание |
|----------|-----|----------|
| circle | string | id окружности |
| angle_deg | number | угол в градусах (необязателен, если задан between) |
| between | [string, string] | id двух точек; точка ложится на дугу между ними |

```json
{"type": "point_on_circle", "id": "D", "circle": "omega", "angle_deg": 145}
{"type": "point_on_circle", "id": "D", "circle": "omega", "between": ["C", "A"]}
```

---

### `inscribed_polygon` — Многоугольник, вписанный в окружность (CH26)

Размещает ВСЕ перечисленные вершины на окружности в циклическом порядке
с минимальной дугой между соседями >= `min_arc_deg` (по умолчанию 15°).
НЕ создаёт стороны — их рисуют отдельные `segment`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| circle | string | id окружности |
| vertices | [string, ...] | id вершин в порядке обхода |
| order | "ccw" / "cw" | направление обхода (по умолчанию ccw) |
| min_arc_deg | number | минимальная дуга между соседями (по умолчанию 15) |
| start_angle_deg | number | базовый угол (необязателен) |

```json
{"type": "inscribed_polygon", "id": "quad_ABCD", "circle": "omega",
 "vertices": ["A", "B", "C", "D"], "order": "ccw"}
```

### `reflect_point` — Центральная симметрия точки (CH27)

Строит точку `id` = 2·center − point (удвоение медианы: «продлим BM за M»).

| Параметр | Тип | Описание |
|----------|-----|----------|
| point | string | id отражаемой точки |
| center | string | id центра симметрии |

```json
{"type": "reflect_point", "id": "D", "point": "B", "center": "M"}
```

---

### `rotate_point` — Поворот точки вокруг центра (CH27)

Поворачивает точку `point` вокруг `center`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| point | string | id поворачиваемой точки |
| center | string | id центра поворота |
| degrees | number | угол в градусах (либо задай `maps`) |
| maps | [string, string] | угол = ∠(maps[0], center, maps[1]); знак такой, что maps[0] переходит в maps[1] |

**Направление положительного угла:** в SVG ось Y направлена ВНИЗ, поэтому
положительный угол даёт поворот ПО ЧАСОВОЙ стрелке (визуально).  Поворот на
+90° переводит точку, лежащую справа от центра, в точку ВНИЗУ.

```json
{"type": "rotate_point", "id": "P2", "point": "P", "center": "B", "degrees": 60}
{"type": "rotate_point", "id": "P2", "point": "P", "center": "B", "maps": ["A", "C"]}
```

### `foot_perpendicular` — Основание перпендикуляра из точки на прямую
Опускает перпендикуляр из точки на прямую, возвращает точку пересечения.

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id точки, из которой опускается перпендикуляр |
| line1 | string | id прямой |

```json
{"type": "foot_perpendicular", "id": "H", "p1": "P", "line1": "l_AB"}
```

## ЛИНИИ

### `segment` — Отрезок
Отрезок между двумя точками.

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id первой точки |
| p2 | string | id второй точки |
| dashed | boolean | пунктир (по умолчанию false) |

```json
{"type": "segment", "id": "AB", "p1": "A", "p2": "B"}
```

---

### `ray` — Луч
Луч из точки p1 через точку p2. Рисуется как отрезок, продолженный до края холста.

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id начальной точки луча |
| p2 | string | id точки направления |

---

### `line` — Прямая
Прямая, проходящая через две точки. Рисуется через весь холст.

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id первой точки |
| p2 | string | id второй точки |
| dashed | boolean | пунктир |

---

### `line_extension` — Продолжение отрезка
Продлевает существующий отрезок/прямую на заданную длину.

| Параметр | Тип | Описание |
|----------|-----|----------|
| origin | string | id исходного отрезка/прямой |
| direction | string | "forward", "backward" или "both" |
| extend_by | number | длина продолжения в пикселях |

---

### `altitude` — Высота
Высота треугольника из вершины p1 на сторону p2-p3.

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id вершины |
| p2, p3 | string | id точек основания |

---

### `median` — Медиана
Медиана из вершины p1 к середине отрезка p2-p3.

| Параметр | Тип | Описание |
|----------|-----|----------|
| p1 | string | id вершины |
| p2, p3 | string | id точек противоположной стороны |

---

### `angle_bisector` — Биссектриса
Биссектриса угла ∠p1-p2-p3 (вершина угла — p2).

| Параметр | Тип | Описание |
|----------|-----|----------|

### `perpendicular_bisector` — Серединный перпендикуляр
