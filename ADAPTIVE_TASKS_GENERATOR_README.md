# 🎯 Генератор задач для Адаптивного теста FORMYLA

## 📋 Обзор

Этот модуль создан для генерации **300 уникальных задач** специально для раздела "Адаптивный тест" платформы FORMYLA. Задачи генерируются через DeepSeek API и сохраняются в отдельную таблицу `adaptive_tasks` (не путать с таблицей `olympiads`!).

## 🗂 Структура матрицы (25 тем × 12 задач = 300 задач)

Адаптивный тест для 5 класса состоит из **25 тем**, разбитых на 5 блоков:

### Блок 1: Арифметика и Текстовые задачи
1. Вычисления (вынос за скобки, группировка)
2. Движение (навстречу, вдогонку)
3. Совместная работа (трубы, покраска)
4. Возраст (отец старше сына...)
5. Метод обратного хода (раскрутить с конца)

### Блок 2: Логика и Алгоритмы
6. Рыцари и Лжецы (кто сказал правду)
7. Переправы (волк, коза, капуста)
8. Переливания (получить объем двумя кувшинами)
9. Взвешивания на чашечных весах (найти фальшивую монету)
10. Календарь и время (дни недели, сдвиги)

### Блок 3: Теория чисел
11. Четность / Нечетность (инварианты)
12. Признаки делимости (на 3, 5, 9, 4)
13. Деление с остатком (периодичность)
14. Последняя цифра большой степени
15. Числовые ребусы (восстановить цифры)

### Блок 4: Аналитическая Геометрия
16. Периметры составных фигур
17. Площади (аналитическое вычисление)
18. Замощения (покрыть доминошками)
19. Углы на циферблате часов
20. Кубики (видимые грани, развертки)

### Блок 5: Комбинаторика
21. Правило умножения (дерево вариантов)
22. Перестановки и расстановки
23. Рукопожатия и турниры (подсчет партий)
24. Принцип Дирихле (кролики и клетки)
25. Теория Игр (выигрышные стратегии)

## 🎚 Уровни сложности (1-7)

- **1-2**: Школьная база, простые вычисления
- **3-4**: Средний уровень, требует рассуждений
- **5-6**: Олимпиадный уровень, нестандартные подходы
- **7**: Финал олимпиады, сложная логика

Для каждой темы генерируется **12 задач** разной сложности (по 2 задачи на уровни 1-6).

## 🔧 Технические детали

### Системный промпт для DeepSeek
```
ОГРАНИЧЕНИЯ ДЛЯ АДАПТИВНОГО ТЕСТА:
1. ЗАПРЕЩЕНЫ задачи, требующие рисунка в ответе
2. МАТЕМАТИКА (LaTeX): строго внутри \( ... \) или \[ ... \]
3. Имена героев и предметы должны меняться
4. Уровень сложности от 1 до 7
```

### Обработка LaTeX в JSON
Скрипт автоматически экранирует LaTeX-команды для корректного JSON:
- `\(` → `\\(`
- `\frac` → `\\frac`
- `\sqrt` → `\\sqrt`

### Retry-логика
При ошибке парсинга JSON скрипт делает до 3 попыток с паузой 1 секунда.
