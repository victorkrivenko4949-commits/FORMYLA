# 🔧 Исправление AI-тьютора: "AI-проверка временно недоступна"

## Проблема
Пользователи постоянно видели сообщение "Ваш ответ принят. AI-проверка временно недоступна" вместо детального разбора от AI-тьютора.

## Найденные проблемы и исправления

### 1. **Недостаточный timeout для сложных задач**
**Проблема:** Разбор задачи с LaTeX формулами и детальным объяснением требует 1000-1500 токенов, что занимает 10-15 секунд. Стандартный timeout мог быть слишком коротким.

**Исправление:**
- ✅ Увеличен `max_tokens` с 1000 до 1500 в [`app.py:3254`](app.py:3254)
- ✅ DeepSeekClient уже имеет `timeout=90` секунд (проверено в [`ai/deepseek_client.py:67`](ai/deepseek_client.py:67))

### 2. **Недостаточное логирование ошибок**
**Проблема:** При ошибке API мы видели только общее сообщение, без деталей о типе ошибки.

**Исправление:**
- ✅ Добавлено детальное логирование в блок `except` ([`app.py:3303`](app.py:3303)):
  - Тип ошибки (`type(e).__name__`)
  - Сообщение ошибки
  - Полный traceback
  - Контекст задачи (текст, ответы)

### 3. **Возможные причины ошибок (для диагностики)**

#### A) Проблемы с парсингом JSON
**Симптом:** `json.JSONDecodeError` или `Invalid \escape`

**Причина:** DeepSeek иногда оборачивает JSON в markdown:
```
```json
{"score": 2, "feedback": "..."}
```
```

**Решение:** Уже реализовано в [`app.py:3264-3267`](app.py:3264):
```python
cleaned_response = re.sub(r'```json\s*', '', cleaned_response)
cleaned_response = re.sub(r'```\s*', '', cleaned_response)
```

#### B) Таймаут запроса
**Симптом:** `TimeoutError` или `ReadTimeout`

**Причина:** Сложные задачи требуют больше времени на генерацию.

**Решение:** ✅ Увеличен `max_tokens` до 1500, `timeout=90` уже установлен в классе.

#### C) Проблемы с API ключом
**Симптом:** `401 Unauthorized` или `403 Forbidden`

**Причина:** Невалидный ключ или закончился баланс.

**Решение:** Создан тестовый скрипт [`test_deepseek_api.py`](test_deepseek_api.py) для проверки.

#### D) Сетевые проблемы
**Симптом:** `ConnectionError`, `NameResolutionError`

**Причина:** Проблемы с интернет-соединением или DNS.

**Решение:** DeepSeekClient имеет retry logic с exponential backoff (2 попытки).

### [`app.py`](app.py)

**Строка 3254:** Увеличен max_tokens
```python
# БЫЛО:
max_tokens=1000

# СТАЛО:
max_tokens=1500  # Увеличено для детального разбора с LaTeX
```

**Строка 3303-3316:** Улучшено логирование ошибок
```python
# БЫЛО:
except Exception as e:
    print(f"[ERROR] DeepSeek API error: {e}")
    traceback.print_exc()
    feedback = "AI-проверка временно недоступна..."

# СТАЛО:
except Exception as e:
    print("="*70)
    print(f"[CRITICAL ERROR] DeepSeek API FAILED")
    print(f"Error Type: {type(e).__name__}")
    print(f"Error Message: {e}")
    print("="*70)
    traceback.print_exc()
    print("="*70)
    print(f"[DEBUG] Task text: {current_task.task_text[:100]}...")
    print(f"[DEBUG] User answer: {user_answer}")
