### **ШАГ 2: КРИТИЧНО! Миграция базы данных**

**На сервере нужно выполнить миграцию для добавления новых колонок:**

```bash
# Подключитесь к серверу (если VPS)
ssh user@your-server.com
cd /path/to/formyla

# Выполните скрипт миграции
python migrate_add_quality_control.py
```

**Что делает скрипт:**
- Добавляет колонки `is_flagged`, `reports_count`, `flagged_reason` в таблицу `adaptive_tasks`
- Создает индекс для быстрой фильтрации
- Проверяет успешность миграции

**Ожидаемый вывод:**
```

[OK] Column flagged_reason added.
```

## 🔧 TROUBLESHOOTING

### Проблема: "OperationalError: no such column: adaptive_tasks.is_flagged"
**Решение:** Выполните миграцию `python migrate_add_quality_control.py`

### Проблема: "Недостаточно задач для 5 класса"
**Решение:** Импортируйте задачи `python import_grade5_to_db.py`

### Проблема: "AI-проверка временно недоступна"
**Решение:** Проверьте переменную окружения `DEEPSEEK_API_KEY` на сервере
