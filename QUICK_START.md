## 📋 Что происходит сейчас?
Скрипт [`generate_adaptive.py`](generate_adaptive.py) генерирует 300 уникальных задач:
- 25 тем × 12 задач разной сложности = 300 задач
- Каждая задача проходит через DeepSeek API
- Время генерации: ~10-15 минут
- Результат сохраняется в `adaptive_tasks_full.json`

## 🔍 Проверить прогресс
```bash
python check_generation_progress.py
```

## 📥 После завершения генерации

### 1. Импортировать задачи в базу данных
```bash
python import_adaptive_tasks.py adaptive_tasks_full.json
```

### 2. Проверить статистику
```bash
python import_adaptive_tasks.py
```

Вы увидите:
- Всего задач в базе
- Распределение по классам
- Распределение по уровням сложности (1-7)
- Топ-10 тем

## 📊 Структура данных

Каждая задача содержит:
```json
{
  "class_level": 5,
  "difficulty_level": 1-7,
  "topic": "Название темы",
  "task_text": "Условие задачи",
  "solution": "Полное решение",
  "criteria_1_point": "Критерий на 1 балл",
  "criteria_2_points": "Критерий на 2 балла"
}
```

## 🔧 Использование в коде

```python
from models import AdaptiveTask

# Получить случайную задачу по теме и уровню
task = AdaptiveTask.query.filter_by(
    class_level=5,
    topic="Взвешивания на чашечных весах (найти фальшивую монету)",
    difficulty_level=4
).first()

# Вывести условие
print(task.task_text)

# Вывести решение
print(task.solution)
```
