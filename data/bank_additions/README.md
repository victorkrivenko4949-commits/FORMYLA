# Добавление задач в FORMYLA_BANK.jsonl (шаг 7)

Здесь лежат пачки задач-кандидатов для дырявых ячеек банка (см. reports/bank_level_report.md,
раздел «Ячейки ниже порога»). В банк они попадают ТОЛЬКО после ручной проверки.

## Порядок

1. Открыть файл пачки (например `G9_T16_L3.jsonl`), решить/проверить каждую задачу: условие корректно, ответ верен, уровень соответствует (L3 = муниципальный этап: нужна идея, а не одна формула).
2. В каждой строке проставить `"review_status": "approved"` (или `"rejected"`), при желании `reviewer` и `review_note`. Можно править `task_text`, `correct_answer`, `solution`, `level`.
3. Локально: `python scripts/bank_add_tasks.py data/bank_additions/G9_T16_L3.jsonl` — отчёт (банк не меняется).
4. Если отчёт устраивает: то же с `--apply`. Скрипт допишет только approved-строки, отбросит дубликаты и проставит position.
5. Закоммитить `FORMYLA_BANK.jsonl` и пачку со статусами отдельным PR. CI `guard` проверит банк (число задач, выдача по темам, верность уровней).

## Формат строки

```json
{"grade": 9, "topic": "Углы и вписанные конфигурации", "level": 3,
 "task_text": "...", "correct_answer": "...", "solution": "...",
 "source": "manual_2026-10-15", "review_status": "pending", "reviewer": "", "review_note": ""}
```

`topic` — русское название темы ровно как в data/theme_titles.json. `position` не указывать — назначит скрипт.
