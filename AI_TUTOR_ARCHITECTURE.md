# AI-Тьютор: Архитектура с 7 специализированными агентами

## Обзор

Реализована система AI-тьютора с 7 независимыми специализированными агентами. Каждый агент имеет свою область экспертизы и сохраняет отдельную историю диалогов.

## 4. 7 ПАРАЛЛЕЛЬНЫХ СОХРАНЕННЫХ ДИАЛОГОВ

### База данных

#### Модель ChatMessage (models.py)
```python
class ChatMessage(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('users.id'), nullable=False)
    agent_type = db.Column(db.String(50), nullable=False, default='general', index=True)
    role = db.Column(db.String(20), nullable=False)  # 'user' или 'assistant'
    content = db.Column(db.Text, nullable=False)
    timestamp = db.Column(db.DateTime, default=datetime.utcnow, index=True)
```

#### Типы агентов
- `algebra` - Агент по алгебре
- `geometry` - Агент по геометрии
- `number_theory` - Агент по теории чисел
- `combinatorics` - Агент по комбинаторике
- `movement` - Агент по задачам на движение
- `logic` - Агент по логике
- `mentor` - Агент-наставник

### Гарантия независимости
- Каждый агент имеет свою историю (фильтр по `user_id` + `agent_type`)

## 5. СИСТЕМНЫЕ ПРОМПТЫ ДЛЯ DEEPSEEK

### Реализация (ai/deepseek_client.py)

#### Метод получения промпта
```python
def get_agent_system_prompt(self, agent_type: str, user) -> str:
    """Получить системный промпт для конкретного агента."""
    
    # Общее правило для ВСЕХ агентов
    no_latex_rule = """
КРИТИЧЕСКИ ВАЖНО - ПРАВИЛА ОФОРМЛЕНИЯ МАТЕМАТИКИ:
- КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО использовать LaTeX: $, $$, \\frac, \\boxed, \\sqrt, \\cdot
- Пиши формулы ТОЛЬКО обычным текстом: a / b, x^2, √25
- Используй Unicode символы: ×, ÷, ≤, ≥, ≠, →, √
"""
    
    prompts = {
        'algebra': f"""Ты — специализированный AI-агент по АЛГЕБРЕ...
{no_latex_rule}""",
        
        'geometry': f"""Ты — специализированный AI-агент по ГЕОМЕТРИИ...
{no_latex_rule}""",
        
        # ... остальные агенты
    }
    
    return prompts.get(agent_type, prompts['mentor'])
```

### Специализация агентов

#### 1. Агент по алгебре (`algebra`)
- Уравнения и неравенства
- Системы уравнений
- Многочлены и их свойства
- Функции и графики
- Прогрессии

#### 2. Агент по геометрии (`geometry`)
- Планиметрия (треугольники, четырехугольники, окружности)
- Стереометрия (многогранники, тела вращения)
- Векторы и координаты
- Геометрические построения

#### 3. Агент по теории чисел (`number_theory`)
- Делимость и НОД/НОК
- Простые числа и факторизация
- Сравнения по модулю
- Диофантовы уравнения

#### 4. Агент по комбинаторике (`combinatorics`)
- Перестановки, размещения, сочетания
- Принцип Дирихле
- Метод включений-исключений
- Графы и деревья

#### 5. Агент по задачам на движение (`movement`)
- Задачи на скорость, время, расстояние
- Движение навстречу и вдогонку
- Задачи на работу и производительность
- Задачи на проценты и концентрации

#### 6. Агент по логике (`logic`)
- Логические задачи и головоломки
- Рыцари и лжецы
- Взвешивания и переливания
- Математическая индукция
- Инварианты и раскраски

#### 7. Агент-наставник (`mentor`)
- Всероссийская олимпиада школьников (ВсОШ)
- Перечневые олимпиады
- Стратегия подготовки
- Тайм-менеджмент
- Апелляции
- **ВАЖНО**: Задачи НЕ решает!

### Правило запрета LaTeX

Для ВСЕХ 7 агентов добавлено жесткое правило:
```
КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО использовать LaTeX: $, $$, \\frac, \\boxed, \\sqrt, \\cdot, \\[, \\], \\(, \\)
Пиши формулы ТОЛЬКО обычным текстом: a / b, x^2, √25, корень из 25
```

Получить историю для конкретного агента.

**Ответ**:

```json
    "content": "Как решить уравнение?",

  {
    "id": 2,
    "role": "assistant",
    "content": "Давай разберем...",
    "timestamp": "2024-01-01T12:00:05"
```

Отправить сообщение агенту.

**Тело запроса**:
```json
{
  "message": "Помоги с задачей",
  "agent_type": "algebra"
}
```

**Ответ**:

```json
{

    "role": "assistant",
```

## Архитектурные решения

### Почему 7 отдельных диалогов?
- Каждый агент специализируется на своей области
- Контекст не смешивается между темами
- Пользователь может вернуться к любому диалогу
- История сохраняется независимо

### Почему запрет LaTeX?
- Обычный текст читается в любом блокноте
- Не требует специальных библиотек для рендеринга
- Проще для копирования и вставки
- Универсальность отображения

### Почему изменяемый размер окна?
- Гибкость для пользователя
- Адаптация под разные экраны
- Возможность видеть больше истории
- Удобство при длинных ответах

## Заключение

Реализована полная архитектура AI-тьютора с 7 специализированными агентами, каждый из которых:
- Имеет свою область экспертизы
- Сохраняет независимую историю диалогов
- Использует специализированный системный промпт
- Не использует LaTeX в ответах

Все требования выполнены В ТОЧНОСТИ по спецификации.
