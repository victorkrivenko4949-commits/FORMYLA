- ✅ Сохранены ответы к задачам

### Метаданные
Каждый пробник содержит:
- `id` — уникальный идентификатор
- `olympiad` — код олимпиады
- `olympiad_title` — название олимпиады
- `year` — год проведения
- `grade` — класс
- `round` — этап (отборочный/заключительный)
- `round_title` — название этапа
- `problems` — массив задач с полями:
  - `num` — номер задачи
  - `text` — условие задачи
  - `answer` — ответ
  - `solution` — решение

## 🔧 Технические детали

### Файлы базы данных
- **Основной файл:** [`olympiads.py`](olympiads.py)
- **Резервные копии:** 
  - [`olympiads_backup.py`](olympiads_backup.py)
  - [`olympiads_with_solutions.py`](olympiads_with_solutions.py)
  - [`olympiads_with_original_solutions.py`](olympiads_with_original_solutions.py)

### Скрипты обработки
- [`fix_olympiad_texts.py`](fix_olympiad_texts.py) — исправление LaTeX индексов
- [`restore_olympiad_conditions.py`](restore_olympiad_conditions.py) — восстановление условий
- [`count_solutions.py`](count_solutions.py) — подсчет статистики
- [`check_updated_solutions.py`](check_updated_solutions.py) — проверка обновлений

### Интеграция с сайтом
- База импортируется в [`app.py`](app.py) как `OLYMPIADS_DB`
- Рендеринг через Jinja2 шаблоны
- LaTeX обрабатывается KaTeX на клиенте
- API эндпоинты для получения пробников и задач
