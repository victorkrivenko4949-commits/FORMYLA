## 🔧 Альтернатива: Запуск через Flask Shell

Если у вас нет прямого доступа к консоли сервера, но есть доступ к Flask shell:

```python
from app import app
from models import db, OlympiadSecret
import json

with app.app_context():
    # Читаем JSON
    with open('secrets_dump.json', 'r', encoding='utf-8') as f:
        secrets_data = json.load(f)
    
    # Импортируем
    for secret_dict in secrets_data:
        secret = OlympiadSecret(
            topic=secret_dict['topic'],
            title=secret_dict['title'],
            content=secret_dict['content'],
            difficulty_level=secret_dict['difficulty_level']
        )
        db.session.add(secret)
    
    db.session.commit()
    print(f"Импортировано: {len(secrets_data)} статей")
```

## 📝 Структура данных

Каждая статья содержит:
- **topic**: Категория (Алгебра, Геометрия, и т.д.)
- **title**: Название метода/приема
- **content**: Markdown-текст статьи с примерами
- **difficulty_level**: Уровень сложности (1-3)

## ⚠️ Важные замечания

1. **Не запускайте `seed_secrets.py` на продакшене** - он использует AI и потратит лимиты API
2. **Используйте готовый `secrets_dump.json`** - это безопасно и быстро
3. **Файл уже в UTF-8** - проблем с кириллицей не будет
4. **Импорт идемпотентный** - можно запускать повторно
