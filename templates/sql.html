SQL — краткий конспект

Напоминание синтаксиса: от SELECT до оконных функций. Примеры — диалект PostgreSQL.

1. SELECT 2. WHERE 3. JOIN 4. GROUP BY 5. Агрегаты 6. Оконные функции 7. CTE и подзапросы 8. Изменение данных

1. SELECT — выборка

Базовый запрос: выбрать столбцы, задать алиасы, отсортировать и ограничить число строк.

SELECT id, name AS имя, price * 1.2 AS price_vat
FROM products
ORDER BY price DESC
LIMIT 10 OFFSET 0;

DISTINCT убирает дубликаты: SELECT DISTINCT category FROM products;

2. WHERE — фильтрация

SELECT *
FROM users
WHERE age BETWEEN 18 AND 30
  AND city IN ('Moscow', 'SPb')
  AND email LIKE '%@gmail.com'
  AND deleted_at IS NULL;

Операторы: = != < > >= <=, AND OR NOT, IN, BETWEEN, LIKE / ILIKE, IS NULL.

3. JOIN — соединение таблиц

SELECT o.id, u.name, o.total
FROM orders AS o
INNER JOIN users AS u ON u.id = o.user_id
LEFT JOIN coupons AS c ON c.order_id = o.id;
  • INNER JOIN — только совпавшие строки;
  • LEFT / RIGHT JOIN — все строки левой / правой таблицы;
  • FULL JOIN — все строки обеих таблиц.

4. GROUP BY — группировка

SELECT category, COUNT(*) AS cnt, AVG(price) AS avg_price
FROM products
GROUP BY category
HAVING COUNT(*) > 5
ORDER BY cnt DESC;

WHERE фильтрует строки до группировки, HAVING — уже группы.

5. Агрегатные функции

  • COUNT(*) — число строк;
  • SUM(x), AVG(x) — сумма и среднее;
  • MIN(x), MAX(x) — минимум и максимум;
  • COUNT(DISTINCT x) — число уникальных.

Полезно для продуктовой аналитики: конверсия $CR=\dfrac{\text{покупки}}{\text{визиты}}$ считается через отношение двух COUNT.

6. Оконные функции

Считают по «окну» строк, не схлопывая их (в отличие от GROUP BY).

SELECT user_id, created_at, total,
  ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY created_at) AS n,
  SUM(total) OVER (PARTITION BY user_id) AS user_total
FROM orders;

Часто: ROW_NUMBER(), RANK(), LAG() / LEAD(), скользящие суммы.

7. CTE и подзапросы

WITH paying AS (
  SELECT user_id, SUM(total) AS revenue
  FROM orders
  GROUP BY user_id
)
SELECT u.name, p.revenue
FROM paying AS p
JOIN users AS u ON u.id = p.user_id
WHERE p.revenue > 1000;

CTE (WITH) делает сложные запросы читаемыми.

8. Изменение данных

INSERT INTO users (name, email) VALUES ('Ann', 'ann@mail.ru');
UPDATE users SET age = age + 1 WHERE id = 7;
DELETE FROM users WHERE deleted_at IS NOT NULL;

Всегда указывай WHERE в UPDATE/DELETE — иначе изменятся все строки.
