ℹ️ Как работает рейтинг?

🔥 Задачи дня

  • +30 XP за каждую правильно решённую задачу дня
  • +10 XP × дни подряд за серию (макс +100 в день)
  • +50 XP бонус за все задачи дня, решённые за день

📅 Месячный пробник

  • +1 XP за каждый % результата (до +100 XP)
  • +5 XP за каждый % улучшения vs прошлый месяц
  • +200 XP за новый личный рекорд

📊 Уровни

L2: 300 XP • L3: 600 • L4: 1000 • L5: 1500 • L6: 2100 • L7: 2800 • L8: 3600 • L9: 4500 • L10: 5500 XP

Важно: задачи из адаптивного теста НЕ дают XP — они только для тренировки. Рейтинг растёт за реальные достижения: привычку, прогресс и олимпиадные победы.
