1. Выборка и выборочные характеристики

Выборка $X_1,\dots,X_n$ — это $n$ независимых одинаково распределённых случайных величин с функцией распределения $F$.

Выборочное среднее и выборочная дисперсия:

$$\overline{X}=\frac{1}{n}\sum_{i=1}^{n}X_i,\qquad S^2=\frac{1}{n}\sum_{i=1}^{n}\bigl(X_i-\overline{X}\bigr)^2.$$

Несмещённая версия дисперсии: $\displaystyle S_0^2=\frac{1}{n-1}\sum_{i=1}^{n}\bigl(X_i-\overline{X}\bigr)^2$, причём $\mathbb{E}\,S_0^2=\sigma^2$.

📝 Пример

Пусть $X_1,\dots,X_n$ — выборка из $\mathcal{N}(a,\sigma^2)$. Показать, что $\mathbb{E}\,\overline{X}=a$ и $\mathrm{D}\,\overline{X}=\sigma^2/n$.

Решение. По линейности $\mathbb{E}\,\overline{X}=\frac1n\sum \mathbb{E}X_i=a$. Ввиду независимости $\mathrm{D}\,\overline{X}=\frac{1}{n^2}\sum \mathrm{D}X_i=\frac{\sigma^2}{n}$.

2. Эмпирическая функция распределения

По выборке строится эмпирическая функция распределения:

$$F_n(y)=\frac{1}{n}\sum_{i=1}^{n}\mathbf{1}\{X_i\le y\}.$$

По теореме Гливенко–Кантелли она равномерно сходится к истинной:

$$\sup_{y\in\mathbb{R}}\bigl|F_n(y)-F(y)\bigr|\xrightarrow{\text{п.н.}}0.$$

📝 Пример

Найти $\mathbb{E}\,F_n(y)$ и $\mathrm{D}\,F_n(y)$ для фиксированного $y$.

Решение. $n F_n(y)\sim \mathrm{Bin}(n,F(y))$, поэтому $\mathbb{E}\,F_n(y)=F(y)$ и $\mathrm{D}\,F_n(y)=\dfrac{F(y)\bigl(1-F(y)\bigr)}{n}$.

3. Точечные оценки

Оценка $\hat\theta=\hat\theta(X_1,\dots,X_n)$ называется:

  • несмещённой, если $\mathbb{E}\,\hat\theta=\theta$;
  • состоятельной, если $\hat\theta\xrightarrow{P}\theta$ при $n\to\infty$;
  • эффективной, если она имеет наименьшую дисперсию в классе несмещённых.

Нижняя граница Рао–Крамера: $\displaystyle \mathrm{D}\,\hat\theta\ge \frac{1}{n\,I(\theta)}$, где $I(\theta)=\mathbb{E}\!\left[\left(\frac{\partial}{\partial\theta}\ln f(X;\theta)\right)^2\right]$ — информация Фишера.

📝 Пример

Показать, что $S_0^2$ несмещённа для $\sigma^2$.

Решение. $\mathbb{E}\sum (X_i-\overline X)^2=(n-1)\sigma^2$, откуда $\mathbb{E}\,S_0^2=\sigma^2$.

4. Метод моментов

Идея: приравнять теоретические моменты к выборочным. Для одного параметра $\theta$:

$$\mathbb{E}_\theta X=\frac{1}{n}\sum_{i=1}^{n}X_i=\overline{X}\;\Rightarrow\;\hat\theta_{\text{ММ}}.$$

📝 Пример

Выборка из равномерного распределения $U[0,\theta]$. Найти оценку методом моментов.

Решение. $\mathbb{E}X=\theta/2=\overline X$, поэтому $\hat\theta_{\text{ММ}}=2\overline X$.

5. Метод максимального правдоподобия

Функция правдоподобия и её логарифм:

$$L(\theta)=\prod_{i=1}^{n}f(X_i;\theta),\qquad \ell(\theta)=\sum_{i=1}^{n}\ln f(X_i;\theta).$$

Оценка МП находится из $\dfrac{\partial \ell}{\partial\theta}=0$.

📝 Пример

Выборка из показательного распределения $f(y)=\lambda e^{-\lambda y}$, $y\ge 0$. Найти $\hat\lambda_{\text{МП}}$.

Решение. $\ell(\lambda)=n\ln\lambda-\lambda\sum X_i$, $\ell'(\lambda)=\dfrac{n}{\lambda}-\sum X_i=0$, откуда $\hat\lambda=\dfrac{1}{\overline X}$.

6. Доверительные интервалы

Интервал $(\theta_1,\theta_2)$ называется доверительным уровня $1-\alpha$, если $\mathbb{P}(\theta_1<\theta<\theta_2)=1-\alpha$.

Для среднего нормальной выборки при известном $\sigma$:

$$\overline{X}\pm z_{1-\alpha/2}\,\frac{\sigma}{\sqrt{n}}.$$

При неизвестном $\sigma$ используется квантиль Стьюдента $t_{1-\alpha/2,\,n-1}$ и $S_0$.

📝 Пример

$n=25$, $\overline X=10$, $\sigma=2$, $\alpha=0{,}05$. Построить доверительный интервал для $a$.

Решение. $z_{0{,}975}=1{,}96$, погрешность $1{,}96\cdot 2/5=0{,}784$. Интервал: $(9{,}22;\,10{,}78)$.

7. Проверка гипотез

Нулевая $H_0$ против альтернативы $H_1$. Ошибки:

  • I рода: отвергнуть верную $H_0$, вероятность $\alpha$;
  • II рода: принять ложную $H_0$, вероятность $\beta$.

Мощность критерия равна $1-\beta$. По лемме Неймана–Пирсона наиболее мощный критерий основан на отношении правдоподобия $\dfrac{L(\theta_1)}{L(\theta_0)}\ge c$.

📝 Пример

Критерий согласия $\chi^2$: статистика $\displaystyle \chi^2=\sum_{k=1}^{m}\frac{(n_k-np_k)^2}{np_k}$ при больших $n$ имеет распределение $\chi^2_{m-1}$.

Вывод. Если $\chi^2>\chi^2_{1-\alpha,\,m-1}$, гипотеза о распределении отвергается.

8. Разбор задач

Подборка классических задач с полными решениями — по всем разделам выше. Формулы в LaTeX.

📝 Задача 1. Несмещённость и состоятельность $\overline{X}$

$X_1,\dots,X_n$ — выборка с $\mathbb{E}X_1=a$, $\mathrm{D}X_1=\sigma^2<\infty$. Доказать, что $\overline{X}$ несмещённа и состоятельна для $a$.

Решение. $\mathbb{E}\,\overline{X}=\frac1n\sum\mathbb{E}X_i=a$ — несмещённость. Далее $\mathrm{D}\,\overline{X}=\sigma^2/n\to0$, поэтому по неравенству Чебышёва $\overline{X}\xrightarrow{P}a$ — состоятельность.

📝 Задача 2. Оценка методом моментов для $U[0,\theta]$

По выборке из равномерного распределения $U[0,\theta]$ найти оценку $\hat\theta$ методом моментов и проверить её несмещённость.

Решение. $\mathbb{E}X=\theta/2$, приравниваем к $\overline{X}$: $\hat\theta_{\text{ММ}}=2\overline{X}$. Тогда $\mathbb{E}\,\hat\theta=2\cdot\theta/2=\theta$ — оценка несмещённа.

📝 Задача 3. Оценка МП для показательного распределения

$f(y)=\lambda e^{-\lambda y}$, $y\ge0$. Найти $\hat\lambda_{\text{МП}}$ и проверить, что это точка максимума.

Решение. $\ell(\lambda)=n\ln\lambda-\lambda\sum X_i$, $\ell'(\lambda)=\frac{n}{\lambda}-\sum X_i=0\Rightarrow\hat\lambda=\frac{1}{\overline{X}}$. Так как $\ell''(\lambda)=-n/\lambda^2<0$, это максимум.

📝 Задача 4. Дисперсия эмпирической функции

Найти $\mathbb{E}\,F_n(y)$ и $\mathrm{D}\,F_n(y)$ для фиксированного $y$.

Решение. $nF_n(y)\sim\mathrm{Bin}(n,F(y))$, поэтому $\mathbb{E}\,F_n(y)=F(y)$, $\mathrm{D}\,F_n(y)=\dfrac{F(y)\bigl(1-F(y)\bigr)}{n}$.

📝 Задача 5. Несмещённая оценка дисперсии

Показать, что $S_0^2=\frac{1}{n-1}\sum (X_i-\overline{X})^2$ несмещённа для $\sigma^2$.

Решение. $\mathbb{E}\sum(X_i-\overline{X})^2=\sum\mathbb{E}X_i^2-n\,\mathbb{E}\overline{X}^2=(n-1)\sigma^2$, откуда $\mathbb{E}\,S_0^2=\sigma^2$.

📝 Задача 6. Доверительный интервал для среднего

$n=25$, $\overline{X}=10$, $\sigma=2$, $\alpha=0{,}05$. Построить 95%-й доверительный интервал для $a$.

Решение. $z_{0{,}975}=1{,}96$, погрешность $1{,}96\cdot 2/5=0{,}784$. Интервал: $(9{,}22;\,10{,}78)$.

📝 Задача 7. Критерий согласия $\chi^2$ (Пирсона)

Кость бросили $n=60$ раз; грани выпали $9,11,8,12,10,10$ раз. Проверить на уровне $\alpha=0{,}05$ гипотезу о равномерности кости.

Решение. Ожидаемые частоты $np_k=10$. $\chi^2=\sum\frac{(n_k-10)^2}{10}=\frac{1+1+4+4+0+0}{10}=1{,}0$. Критическое значение $\chi^2_{0{,}95,\,5}=11{,}07$. Так как $1{,}0<11{,}07$, гипотеза о равномерности не отвергается.

📝 Задача 8. Неравенство Рао–Крамера для $\mathcal{N}(a,\sigma^2)$

При известном $\sigma$ найти нижнюю границу дисперсии несмещённых оценок $a$ и показать, что $\overline{X}$ эффективна.

Решение. $\ln f=-\frac{(x-a)^2}{2\sigma^2}+\text{const}$, $\frac{\partial}{\partial a}\ln f=\frac{x-a}{\sigma^2}$, информация Фишера $I(a)=1/\sigma^2$. Граница Рао–Крамера $\dfrac{1}{nI(a)}=\dfrac{\sigma^2}{n}=\mathrm{D}\,\overline{X}$ — достигается, значит $\overline{X}$ эффективна.
