# Тест: Разнообразие задач в Бесплатном пробнике

## Что было реализовано

### 1. История математических идей в сессии
- При старте пробника (`/free_mock/start`) создаются два списка в сессии:
  - `session['mock_task_ideas']` - краткие названия математических идей
  - `session['mock_task_texts']` - первые 150 символов текста каждой задачи

### 2. Усиленный промпт для LLM
Добавлен визуально выделенный блок с жесткими требованиями:

```
╔══════════════════════════════════════════════════════════════════════════════╗
║ КРИТИЧЕСКИ ВАЖНО: ЗАЩИТА ОТ ПОВТОРЕНИЙ МАТЕМАТИЧЕСКИХ ИДЕЙ                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

В ЭТОМ ПРОБНИКЕ УЖЕ ИСПОЛЬЗОВАНЫ СЛЕДУЮЩИЕ МАТЕМАТИЧЕСКИЕ ИДЕИ:
- [список идей из истории]

ТВОЯ НОВАЯ ЗАДАЧА ДОЛЖНА БЫТЬ АБСОЛЮТНО УНИКАЛЬНОЙ!

🚫 СТРОГО ЗАПРЕЩЕНО:
   • Повторять методы решения из списка выше
   • Менять только числа в старых задачах
   • Использовать похожие конструкции или сюжеты
   • Генерировать задачи на те же математические концепции

✅ ОБЯЗАТЕЛЬНО:
   • Придумай СОВЕРШЕННО НОВУЮ математическую идею
   • Используй ДРУГОЙ метод решения
   • Выбери ДРУГУЮ подтему из раздела математики
   • Создай ОРИГИНАЛЬНЫЙ сюжет (если это текстовая задача)
```

### 3. Логирование в консоль
При генерации каждой задачи в терминал выводится:
```
[Free Mock] 📋 Генерирую задачу №X. Исключенные идеи: [список]
[Free Mock] 💾 Сохранена идея: 'Название темы'. Всего идей в истории: X
```

## Как проверить

1. Откройте `/free_mock/start` в браузере
2. Начните генерацию задач
3. Смотрите в терминал - там будут логи с исключенными идеями
4. Проверьте, что задачи действительно разные по математической сути

## Технические детали

**Где хранится история:** В Flask session (серверная сессия, привязанная к cookie пользователя)

**Когда очищается:** При каждом новом заходе на `/free_mock/start`

**Что сохраняется:** 
- Тема задачи (из поля `topic` в JSON ответе LLM)
- Первые 150 символов текста задачи

**Как передается в промпт:**
- История идей вставляется в system prompt перед генерацией каждой новой задачи
- LLM видит все предыдущие темы и получает жесткий запрет на повторения
