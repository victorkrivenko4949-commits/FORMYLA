**Умные фильтры:**
```python
# Фильтр 1: Размер < 100px (иконки)
if width < 100 or height < 100: continue

# Фильтр 2: QR-коды (квадратные 100-300px)
if 100 <= width <= 300 and abs(width - height) < 50: continue

# Фильтр 3: Узкие/длинные (aspect ratio)
if aspect_ratio > 10 or aspect_ratio < 0.1: continue

# Фильтр 4: Маленький файл (< 2KB)
if len(image_bytes) < 2048: continue
```

## 2. Failure Mode Analysis

### Успешные решения

✅ **Проблема:** Сайты олимпиад возвращают 404  
**Решение:** Найдены рабочие URL через анализ структуры сайтов

✅ **Проблема:** Playwright зависает при клике на PDF  
**Решение:** Гибридный подход (Playwright для парсинга + requests для скачивания)

✅ **Проблема:** Извлекаются логотипы и QR-коды  
**Решение:** Умные фильтры по размеру, aspect ratio, размеру файла

✅ **Проблема:** 291 изображение без привязок  
**Решение:** Order Linker с логикой "N задач = N картинок"

✅ **Проблема:** Нет доступа к Vision API  
**Решение:** Логика порядка вместо компьютерного зрения
